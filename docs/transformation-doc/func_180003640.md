# sub_180003640 — per-keypoint descriptor nearest-neighbour matcher (builds the correspondence table for transform fitting)

For each query keypoint in a frame, this routine scans a candidate list of train keypoints,
computes the **Hamming distance** between their 128-bit (16-byte) descriptors via the helper
`sub_1800034e0`, tracks the **best (`esi`) and second-best (`edi`) distances**, applies a
**Lowe-style ratio gate** plus a **spatial (Δx,Δy) gate**, and on success appends a
correspondence record (query coord pair, train coord pair, query-keypoint-index, accepted
match-distance `esi`) into a `0x1c`-stride output table that is capped at **100 (0x64)** entries.
The table it fills is exactly the (qx,qy)/(tx,ty)/score set that the downstream rigid
similarity-transform fit consumes.

> NOTE: this function does **not** itself do Q16 / matrix math. It produces the *correspondences*
> (the input data) for the transform fit. The matrix/affine arithmetic lives in the caller chain
> (`sub_180003880` → fitters). Flagged `is_transform_math = true` only because it produces the
> coordinate-pair correspondence set the rigid transform is fit to.

---

## Signature

x64 Windows ABI. The prologue does `mov rax,rsp` then homes the 4 register args at
`[rax+0x08..0x20]`, so the first four args are the usual rcx/rdx/r8/r9; the rest are real
stack args read at `[rsp+0x90 .. 0xc8]`.

```c
// Best-effort reconstructed signature.
// KP            : 32-byte (0x20) keypoint record { ... +0x0C:int field, +0x14:int x?, +0x18:int y? ... }
// CORR          : 0x1c-byte (28) correspondence record (output table element), see field table.

int sub_180003640(
    void   **query_kp_arrays,   // rcx  -> array of pointers; [*rcx] = base of query-frame KP array (stride 0x20)
    void   **train_kp_arrays,   // rdx  -> array of pointers; [*rdx] = base of train-frame KP array (stride 0x20)  (this ptr = "r9" alias in disasm)
    void   **a_third,           // r8   -> array of pointers; r12 = *r8 used to fetch query KP base too (see notes)
    void   **a_fourth,          // r9   -> array of pointers; rdx_loop = *r9  (train descriptor base index)
    /* stack: */
    uint8_t *query_idx_list,    // [rsp+0xb0]  rbp -> list of query keypoint indices (1 byte each); advanced each outer iter
    uint8_t *cand_idx_list,     // [rsp+0xb8]  r8inner -> per-query list of candidate train indices (1 byte each)
    int      cand_count,        // [rsp+0xc0]  outer loop bound  (number of query entries to process)
    int      inner_count,       // [rsp+0xc8]  ecx -> number of candidate train descriptors to test per query
    /* pointers used in the "accept" block, read off the stack: */
    int     *out_count_ptr,     // [rsp+0x98]  rdx_acc -> *ptr = current number of records in CORR table (the 0x64 cap counter)
    CORR    *out_table,         // [rsp+0x90]  r8_acc  -> base of the 0x1c-stride correspondence output table
    void   **train_coord_src,   // [rsp+0xa0]  r12_acc -> array; [*ptr] = base used to copy TRAIN (qx?,qy?) bytes
    void   **query_coord_src    // [rsp+0xa8]  r9_acc  -> array; [*ptr] = base used to copy QUERY (qx?,qy?) bytes
);
// returns: eax = 0 (r14d is xored to 0 at entry and never meaningfully returned; the real
//          output is the appended records and *out_count_ptr).
```

The exact identity of the four pointer-of-pointer args vs. the four stack source pointers is
partly inferred (multiple of them index keypoint arrays at stride 0x20 / records at stride 0x1c).
What is solid: stride **0x20** keypoint records, stride **0x1c** output records, the score gates,
and the 0x64 cap.

## Pseudocode

```c
int sub_180003640(void **rcx, void **rdx_train, void **r8, void **r9_arg, /*stack...*/)
{
    // --- prologue / arg homing ---                              // 0x180003640
    // [rax+0x08]=rcx [rax+0x10]=rdx [rax+0x18]=r8 [rax+0x20]=r9   // 0x180003643..0x18000364f
    // push r12,r13,r14 ; sub rsp,0x70                            // 0x180003653..0x180003659

    r14d = 0;                                                     // 0x18000365d  (running prev-best train kp index)
    r12  = r8;                                                    // 0x180003660
    int outer_n = *(int*)(rsp+0xc0);     // cand_count            // 0x180003663
    r13d = 0;                            // best train kp idx     // 0x18000366b
    r11d = 0;                            // outer loop counter i  // 0x18000366e
    *(int*)(rsp+0x20) = 0;              // saved copy of i        // 0x180003671
    if (outer_n <= 0) goto L_epilogue;   // jbe 0x18000386c       // 0x180003676

    int inner_n = *(int*)(rsp+0xc8);     // inner_count (ecx)     // 0x18000367c
    // home rbx,rbp,rsi,rdi,r15 into shadow slots                 // 0x180003683..0x18000369f
    rbp = *(void**)(rsp+0xb0);           // query_idx_list ptr    // 0x18000368b

    // ================= OUTER LOOP over query keypoints =========
L_outer: // 0x1800036a0
    rax = *(void**)r12;                                           // 0x1800036a0  query KP array base
    rdx = *(void**)r9_arg;                                        // 0x1800036a4  train KP array base
    ebx = (uint8_t)*rbp;                  // query kp index byte  // 0x1800036a7
    r8  = *(void**)(rsp+0xb8);            // cand_idx_list base    // 0x1800036ab
    rbx <<= 5;                            // *0x20 -> query offset // 0x1800036b3
    esi = 0x80;                           // best distance  = 128 // 0x1800036b7  (init, 16 bytes*8 bits)
    r15 = *(void**)(rax + rbx);           // base of query desc set// 0x1800036bc
    eax = (uint8_t)*r8;                   // first cand idx byte   // 0x1800036c0
    edi = esi;                            // second-best dist =128 // 0x1800036c4
    rax <<= 5;                            // *0x20 -> train offset // 0x1800036c6
    test ecx,ecx  (ecx == inner_n)                                // 0x1800036ca
    *(rsp+0x28) = rbx;   // save query offset                     // 0x1800036cc
    r12 = *(void**)(rax + rdx);           // base of train desc    // 0x1800036d1
    *(rsp+0x30) = rdx;   // save train KP base                    // 0x1800036d5
    if (inner_n == 0) goto L_after_inner; // je 0x180003735       // 0x1800036da

        rbx = r8;            // rbx -> walking cand_idx_list ptr   // 0x1800036dc
        ebp = inner_n;       // inner counter                     // 0x1800036df

        // ---------- INNER LOOP over candidate train descriptors ----------
    L_inner: // 0x1800036e1
        r9d = 0x10;          // arg4 = 16 bytes descriptor length  // 0x1800036e1
        r8d = 0;             // arg3 = 0 (start offset)            // 0x1800036e7
        rdx = r12;           // arg2 = train descriptor ptr        // 0x1800036ea
        rcx = r15;           // arg1 = query descriptor ptr        // 0x1800036ed
        eax = sub_1800034e0(r15, r12, 0, 16); // Hamming distance  // 0x1800036f0
        r12 += 0x10;         // advance to next 16-byte train desc // 0x1800036f5
        if (eax >= esi) goto L_chk2;   // jae 0x18000370a          // 0x1800036f9
            // new best
            r13d = r14d;                 // demote old best->2nd?  // 0x1800036fd  (see note)
            r14d = (uint8_t)*rbx;        // best train kp idx byte // 0x180003700
            edi  = esi;                  // second-best = old best // 0x180003704
            esi  = eax;                  // best = new distance    // 0x180003706
            goto L_inner_next;           // jmp 0x180003714        // 0x180003708
    L_chk2: // 0x18000370a
            if (eax >= edi) goto L_inner_next; // jae 0x180003714  // 0x18000370a
            r13d = (uint8_t)*rbx;        // second-best kp idx     // 0x18000370e
            edi  = eax;                  // second-best = new dist // 0x180003712
    L_inner_next: // 0x180003714
        rbx += 1;                        // next cand idx byte     // 0x180003714
        rbp -= 1;                                                  // 0x180003718
        if (rbp != 0) goto L_inner;      // jne 0x1800036e1        // 0x18000371c

        // restore spilled regs after inner loop
        r11d = *(int*)(rsp+0x20);        // i                      // 0x18000371e
        rbx  = *(void**)(rsp+0x28);      // query offset           // 0x180003723
        rbp  = *(void**)(rsp+0xb0);      // query_idx_list ptr     // 0x180003728
        rdx  = *(void**)(rsp+0x30);      // train KP base          // 0x180003730

    // ================= SCORE GATING =================
L_after_inner: // 0x180003735
    edi = edi * 0x64;                    // second_best * 100      // 0x180003735  (Lowe ratio numerator scaling)
    r10d = r14d;                         // best train kp idx      // 0x180003738
    ecx  = r13d;                         // second-best kp idx     // 0x18000373b
    rcx  <<= 5;     // *0x20 -> 2nd kp offset                      // 0x18000373e
    r10  <<= 5;     // *0x20 -> best kp offset                     // 0x180003742
    eax  = edi;                          // = second_best*100      // 0x180003746

    // Δ between BEST kp coords and SECOND-best kp coords (fields +0x14,+0x18 = x,y):
    r9d = *(int*)(r10 + rdx + 0x14);     // best.x                 // 0x180003748
    r8d = *(int*)(r10 + rdx + 0x18);     // best.y                 // 0x18000374d
    r9d -= *(int*)(rcx + rdx + 0x14);    // dx = best.x - 2nd.x    // 0x180003752
    r8d -= *(int*)(rcx + rdx + 0x18);    // dy = best.y - 2nd.y    // 0x180003757

    edx = 0;
    ecx = esi + 1;                       // best_dist + 1          // 0x18000375e
    eax = (uint32_t)(second_best*100) / (best_dist + 1);  // div   // 0x180003761  (unsigned)
    if (eax > 0x70) goto L_ratio_fail;   // ja 0x18000377d (>112)  // 0x180003763
        // ratio passed -> also require best & 2nd be spatially close
        r8d = r8d * r8d;                 // dy*dy                  // 0x180003768  (signed imul)
        r9d = r9d * r9d;                 // dx*dx                  // 0x18000376c
        r8d = r8d + r9d;                 // dx*dx + dy*dy          // 0x180003770
        if (r8d >= 0x24) goto L_skip;    // jae 0x180003819 (>=36) // 0x180003773

L_ratio_fail: // 0x18000377d
    if (esi >= 0x60) goto L_skip2;       // ja/jae 0x180003807 (>=96)// 0x18000377d  (absolute best-dist gate)

    // ================= ACCEPT: append correspondence record =================
    rdx = *(void**)(rsp+0x98);           // out_count_ptr          // 0x180003786
    r8  = *(void**)(rsp+0x90);           // out_table base         // 0x18000378e
    r12 = *(void**)(rsp+0xa0);           // train_coord_src array  // 0x180003796
    ecx = *(int*)rdx;                    // n = current count      // 0x18000379e
    rax = *(void**)r12;                  // train coord base       // 0x1800037a0
    r9  = *(void**)(rsp+0xa8);           // query_coord_src array  // 0x1800037a4
    rcx = ecx * 0x1c;                    // record offset = n*28   // 0x1800037ac

    // record[n] @ (out_table + n*0x1c):
    //   +0x00 (8B): train coords (qword at train_coord_base + query_off + 0x14)
    *(uint64_t*)(rcx + r8 + 0x00) = *(uint64_t*)(rax + rbx + 0x14);   // 0x1800037b0..0x1800037b5
    rax = *(void**)r12; ecx = *(int*)rdx;
    //   +0x10 (4B): int at train_coord_base + query_off + 0xC
    *(uint32_t*)(rcx + r8 + 0x10) = *(int*)(rax + rbx + 0xC);          // 0x1800037bf..0x1800037c7
    ecx = *(int*)rdx; rax = *(void**)r9;
    //   +0x08 (8B): query coords (qword at query_coord_base + best_off(r10) + 0x14)
    *(uint64_t*)(rcx + r8 + 0x08) = *(uint64_t*)(rax + r10 + 0x14);    // 0x1800037d1..0x1800037da
    rax = *(void**)r9; ecx = *(int*)rdx;
    //   +0x14 (4B): int at query_coord_base + best_off(r10) + 0xC
    *(uint32_t*)(rcx + r8 + 0x14) = *(int*)(rax + r10 + 0xC);          // 0x1800037e4..0x1800037ed
    eax = *(int*)rdx; rax = eax * 0x1c;
    //   +0x18 (4B): the accepted best match distance (esi)
    *(uint32_t*)(rax + r8 + 0x18) = esi;                              // 0x1800037f4..0x1800037f8

    *(int*)rdx += 1;                    // ++count                 // 0x1800037fd
    if (*(int*)rdx == 0x64) goto L_done; // == 100 -> stop entirely // 0x180003800..0x180003803
    goto L_continue;                    // jmp 0x180003829          // 0x180003805

L_skip2: // 0x180003807   (esi >= 0x60 path: just reload spilled ptrs, no append)
    r9  = *(void**)(rsp+0xa8);                                       // 0x180003807
    r12 = *(void**)(rsp+0xa0);                                       // 0x18000380f
    goto L_continue;                                                 // 0x180003817

L_skip: // 0x180003819   (spatial gate failed: reload ptrs, no append)
    r9  = *(void**)(rsp+0xa8);                                       // 0x180003819
    r12 = *(void**)(rsp+0xa0);                                       // 0x180003821

    // ================= OUTER LOOP TAIL =================
L_continue: // 0x180003829
    ecx  = *(int*)(rsp+0xc8);           // reload inner_count       // 0x180003829
    r11d += 1;                          // ++i                      // 0x180003830
    rbp  += 1;                          // ++query_idx_list ptr     // 0x180003834
    cmp r11d, *(int*)(rsp+0xc0)         // i < cand_count ?         // 0x180003838
    *(int*)(rsp+0x20) = r11d;           // save i                   // 0x180003840
    *(void**)(rsp+0xb0) = rbp;          // save query_idx_list ptr  // 0x180003845
    if (i < cand_count) goto L_outer;   // jb 0x1800036a0           // 0x18000384d

L_done: // 0x180003853  (restore callee-saved spilled in shadow)
    rdi = *(rsp+0x50); rsi = *(rsp+0x58); rbp = *(rsp+0x60);         // 0x180003853..0x18000385d
    rbx = *(rsp+0x68); r15 = *(rsp+0x48);                           // 0x180003862..0x180003867

L_epilogue: // 0x18000386c
    rsp += 0x70; pop r14; pop r13; pop r12;                         // 0x18000386c..0x180003874
    return eax;   // (r14d-derived; not a meaningful status)        // 0x180003876
}
```

### Note on the best/second-best demotion (0x1800036fd–0x180003712)
The "new best" branch sets `r13d = r14d` *before* updating `r14d`, and `edi = esi` before
`esi = eax`. So `r14d`/`esi` track the **best** train-kp-index/distance and `r13d`/`edi` track
the **second-best**. After the loop, the Δ(coord) gate is computed between **best** kp (`r10`)
and **second-best** kp (`rcx`), and the accepted record stores the **best** coords and **best**
distance `esi`. The `*100 / (esi+1)` then `> 0x70` test is a Lowe ratio: reject if
`second_best*100 / (best+1) > 112`, i.e. accept the unambiguous-or-close cases as further
qualified by the spatial gate.

## Struct fields & constants

### Keypoint record (stride **0x20**, indexed by 1-byte index << 5)
| Offset | Size | Read at | Meaning (inferred) |
|--------|------|---------|--------------------|
| +0x00  | ptr  | 0x1800036bc / 0x1800036d1 | pointer to the 16-byte descriptor buffer for this kp |
| +0x0C  | int  | 0x1800037bf / 0x1800037e4 | int coord/field copied to record +0x10 / +0x14 (likely angle/orientation or a packed coord) |
| +0x14  | int  | 0x180003748 / 0x180003752 / 0x1800037b0 | **x** (used in Δ; low dword of the 8-byte coord pair copied to record) |
| +0x18  | int  | 0x18000374d / 0x180003757 | **y** (used in Δ; high dword of the +0x14 qword) |

Note +0x14 is copied as an **8-byte qword** into the record (so it carries both +0x14 and +0x18 = the (x,y) pair).

## Confidence & open questions

**Solid:**
- Control flow, all addresses, loop bounds, and the two gates are transcribed directly.
- Keypoint stride 0x20, output record stride 0x1c, descriptor length 16 bytes.
- `sub_1800034e0` is a Hamming/popcount distance (read & confirmed).
- The three accept conditions: Lowe ratio `2nd*100/(best+1) <= 112`, spatial `dx²+dy² < 36`,
  OR absolute fallback `best < 96`; and the hard cap of 100 records.
- Record field layout and which source coords land where.

**Inferred / open:**
- Exact semantics of the four pointer-of-pointer args vs. the four stack source pointers. They all
  ultimately index the same kp arrays at stride 0x20; the split (`query_kp_arrays` vs
  `train_coord_src` vs `query_coord_src`) is named by *usage* in the accept block, not proven to be
  distinct objects. Hooks #1/#6 will disambiguate at runtime.
- Field `+0xC` meaning (orientation? frame id? packed coord?) — only that it is an int copied alongside the (x,y) pair.
- The control flow at 0x180003766 uses `ja` (above, unsigned) for the ratio `>0x70`; the fallthrough
  reaches the spatial gate. If the ratio passes AND spatial fails (`>=0x24`) it jumps to L_skip
  (no append). If ratio fails (`ja`) it falls to the absolute gate `esi>=0x60`. So a high-ratio
  match can still be accepted purely on a very small absolute Hamming (<96). Confirmed by the
  branch structure but worth runtime confirmation via hooks #4/#5/#6.
- Return value is not a meaningful status (eax derived from r14d zero-init / last best idx); callers
  presumably read the count via `out_count_ptr`.
```
