# sub_180007480 — RANSAC-style 2-point similarity-transform estimator with inlier counting + LSQ refit

This is the geometric core that, given two equal-length lists of corresponding 2D
points (set A in `rdx`, set B in `r8`), searches over **pairs of correspondences**
to build a minimal 2-point Q16 rigid/similarity transform (`sub_180007390` →
`sub_180006e10`), counts how many of the N correspondences are **inliers** under
that transform (apply via `sub_180007450` → `sub_180006bc0`, then compare squared
residual to the threshold `arg8`), keeps the pair giving the most inliers, and —
if the best inlier count ≥ 3 — re-fits a least-squares transform from **all the
inliers** (`sub_1800073f0` → `sub_180006f20`) and returns the inlier count.

In short: **RANSAC over all C(N,2) point-pairs → best similarity transform →
least-squares refinement on the consensus set.** The fitted transform (`a,b,tx,ty`
Q16) is what ultimately lands in the `sec0_pre` inter-frame registration table.

```c
// Best-effort inferred signature.
// Points are 8-byte records = two int32 (x,y) read as a qword and copied verbatim.
// "ctx0" / "ctx1" are opaque workspaces handed down to the solver/applier helpers.

int sub_180007480(

    Point  *A,             // rdx  (arg1) : array A of N source points (8 bytes each: int32 x, int32 y)
    Point  *B,             // r8   (arg2) : array B of N matching dest points (8 bytes each)
    void   *ctx_apply,     // r9   (arg3) : ctx passed to sub_180007450 (transform-apply)
    /* stack */
    ??     arg5,           // [rsp+0xD0] : referenced via [rsp+0xb0..0xc0] reloads — see notes
    Point *Aout,           // [rsp+0xD8] (arg6) : also = base used in the per-pair inlier loop
    int    N,              // [rsp+0xE0] (arg7) : number of correspondences (loop bound)
    int    threshSq,       // [rsp+0xE8] (arg8) : inlier acceptance threshold (squared pixel dist)
    void  *outA_x,         // [rsp+0xF0] (arg9)  : LSQ-refit consensus output buffer (passed to refit)
    void  *outA_y,         // [rsp+0xF8] (arg10) : "
    void  *outB           // [rsp+0x100] (arg11): "
);
// returns: number of inliers of the best (refined) model, or 0 on any failure / <3 inliers
```

NOTE on the stack-arg numbering: after the prologue (`push` of
rbp,rsi,rdi,r12-r15 = 0x38, then `sub rsp,0x70`) the incoming 5th stack argument
(`entry+0x28`) sits at `[rsp+0xD0]`. The slots `[rsp+0xb0]/[rsp+0xb8]/[rsp+0xc0]`
are this function's **own home space** holding the spilled register args
rcx/rdx/r8 (i.e. `ctx_fit2`, `A`, `B`) which are reloaded after each helper call.
`[rsp+0xc8]` holds the saved `rbx` (restored in the epilogue), **not** an argument.

Register aliases established at entry and held across the loops:
- `r9`  = `ctx_fit2` (arg0)            — kept in `r9` for `sub_180007390`/`sub_1800073f0` (passed as rcx there)
- `rsi` = `A` (arg1)                   — base of source-point array
- `rdi` = `B` (arg2)                   — base of dest-point array
- `r15d`= `N` (arg7)
- `ebx` / `ebp` = best pair indices `(best_i, best_j)`, initialised to -1
- `[rsp+0x20]` = best inlier count so far (`bestCnt`), init 0
- `[rsp+0x2c]`,`[rsp+0x24]`,`[rsp+0x28]` = scratch copies of best_i / best_j / outer index

## Pseudocode

```c
int sub_180007480(ctx_fit2, A, B, ctx_apply, arg5, Aout, N, threshSq, outA_x, outA_y, outB)
{
    // ---- prologue / init ----                                              // 0x180007480
    r15d = N;                                  // arg7                         // 0x1800074a3
    int best_i = -1;        // ebx                                            // 0x1800074ab
    int best_j;             // ebp = -1                                       // 0x1800074c7
    int bestCnt = 0;        // [rsp+0x20], r13d=0                             // 0x1800074ae
    rsi = A;  rdi = B;  r9 = ctx_fit2;                                        // 0x1800074b4..c0
    [rsp+0x2c] = -1;        // best_i scratch                                  // 0x1800074c3
    [rsp+0x24] = -1;        // best_j scratch                                  // 0x1800074c9
    [rsp+0x20] = 0;         // bestCnt                                         // 0x1800074cd
    [rsp+0x28] = 0;         // outer index scratch                            // 0x1800074d1
    if (N <= 0) goto L_done_zero_check;        // jle 0x1800077b4              // 0x1800074d5

    r11 = (char*)A - (char*)B;                 // ptr delta A-B                // 0x1800074e6
    [rsp+0x58] = B;                            // r10 = B (outer ptr)          // 0x1800074e1
    r8 = Aout;                                 // arg6, [rsp+0xd8]             // 0x1800074e9
    [rsp+0x38] = r11;                          // saved A-B delta              // 0x1800074f1

    // =========================================================================
    // OUTER LOOP  over i = 0 .. N-1   (r10 = &B[i], r8 = &Aout[i] stepping +8/+4)
    // =========================================================================
L_outer:                                                                      // 0x180007500
    // P_i in dest space: B[i] (qword) and ... see helper inputs below
    [rsp+0x60] = *(qword*)(r10 + r11);   // = A[i]  (r10+ (A-B) = &A[i])       // 0x180007500
    [rsp+0x48] = *(qword*)(r10);          // = B[i]                            // 0x180007509
    int i1 = idx + 1;                     // eax = rdx+1                       // 0x180007511
    [rsp+0x40] = i1;  r12d = i1;                                              // 0x180007517/1b
    if (i1 >= N) goto L_after_inner;      // jge 0x180007660                   // 0x18000751e

    r14 = r8 + 4;                         // &Aout[i].y                        // 0x180007524
    r13 = r10 + 8;                        // &B[i+1]                           // 0x180007528

    // -------------------------------------------------------------------------
    // INNER LOOP  over j = i+1 .. N-1   (r13=&B[j], r14=&Aout[i].y? see note)
    // -------------------------------------------------------------------------
L_inner:                                                                      // 0x180007530
    [rsp+0x68] = *(qword*)(r11 + r13);    // = A[j]  (r13 + (A-B) = &A[j])     // 0x180007530
    int cx = *(int*)r8;                   // Aout[i].x  (= B[i].x region)      // 0x180007534
    int dx = *(int*)r14;                  // Aout[i].y                         // 0x180007537
    [rsp+0x50] = *(qword*)r13;            // = B[j]                            // 0x18000753f

    // gate: skip pairs whose |cx-dx| (an int1D coordinate-difference) > 16
    int e = cx - dx;                                                          // 0x18000754a
    if (e <= 0) e = dx - cx;              // abs                               // 0x180007550
    if (e > 0x10) goto L_inner_next;      // jg 0x18000763e (skip far pair)    // 0x180007557

    // ---- build minimal 2-point transform from {A[i],A[j]} -> {B[i],B[j]} ----
    // sub_180007390(ctx_fit2, out=&[rsp+0x30]?, pA=&[rsp+0x60], pB=&[rsp+0x48])
    r8  = &[rsp+0x48];   rdx = &[rsp+0x60];   rcx = ctx_fit2(r9);             // 0x18000755d..67
    ok = sub_180007390(rcx, rdx, r8);     // -> fills 4 dwords (a,b,tx,ty)     // 0x18000756a
    if (!ok) goto L_inner_next_noctx;     // je 0x180007629                    // 0x180007571

    // ---- count inliers of this model over all k = 0..N-1 ----
    ebp = N;                              // loop counter                      // 0x180007577
    r15 = [rsp+0xb0];                     // = ctx_fit2 (home arg0) reused as ctx_apply src
    int inl = 0;          // ebx                                              // 0x180007582
  L_count:                                                                    // 0x180007590
    // sub_180007450(out=&[rsp+0x30], pt=A[k]=rdx=rsi, ctx=r8=r15)            // 0x180007590..98
    sub_180007450(&[rsp+0x30], rsi, r15);  // apply transform -> [rsp+0x30]=x,[+0x34]=y
    int tx = [rsp+0x30];  int ty = [rsp+0x34];                                // 0x1800075a0/a5
    ty -= *(int*)(rdi + 4);   // - B[k].y                                      // 0x1800075a9
    tx -= *(int*)(rdi);       // - B[k].x                                      // 0x1800075ac
    int resid = ty*ty + tx*tx;                                                // 0x1800075af..b6
    if (resid <= threshSq)   inl++;       // cmp [rsp+0xe8]; jg skip; add 1    // 0x1800075b9..c2
    rsi += 8;  rdi += 8;                  // next A[k], B[k]                   // 0x1800075c5/c9
    if (--ebp != 0) goto L_count;         // jne 0x180007590                   // 0x1800075cd/d1

    // ---- keep best ----
    int prevBest = [rsp+0x20];            // bestCnt                           // 0x1800075d3
    r15d = N;  rdi = B(home c0);  rsi = A(home b8); r9 = ctx(home b0);        // 0x1800075d7..f8
    r8 = Aout; r11 = A-B delta;                                               // 0x1800075f9/601
    if (inl <= prevBest) {                // jle 0x18000761f                   // 0x180007606
        best_i = [rsp+0x2c];  best_j = [rsp+0x24];   // restore (no update)   // 0x18000761f/623
        goto L_inner_next2;               // 0x180007642
    }
    // update best = this (i,j) pair, bestCnt = inl
    best_j = [rsp+0x28];                  // ebp = outer idx i                 // 0x180007608
    [rsp+0x20] = inl;                     // bestCnt = inl                     // 0x18000760e
    best_i = r12d;                        // ebx = inner idx j                 // 0x180007612
    [rsp+0x24] = best_j;                  // save                             // 0x180007615
    [rsp+0x2c] = best_i;                  // save                             // 0x180007619
    goto L_inner_next2;                   // jmp 0x180007642                   // 0x18000761d

  L_inner_next_noctx:                     // model build failed                // 0x180007629
    r9 = ctx(home b0); r8 = Aout(home d8); r11 = A-B delta;                   // 0x180007629..39
  L_inner_next:                                                               // 0x18000763e
    int restoredBest = [rsp+0x20];        // ecx (unused fallthrough)          // 0x18000763e
  L_inner_next2:                                                              // 0x180007642
    r12d++;  r13 += 8;  r14 += 4;                                            // 0x180007642..4a
    if (r12d < N) goto L_inner;           // jl 0x180007530                    // 0x18000764e/51
    r10 = [rsp+0x58];  eax = [rsp+0x40] (= i+1);                              // 0x180007657/5c

L_after_inner:                                                                // 0x180007660
    r10 += 8;  r8 += 4;                   // advance outer ptrs               // 0x180007660/64
    [rsp+0x28] = (idx = i+1);                                                 // 0x18000766d
    [rsp+0x58] = r10;  [rsp+0xd8] = r8;                                       // 0x180007671/76
    if (i+1 < N) goto L_outer;            // jl 0x180007500                    // 0x18000767e

    // =========================================================================
    // POST: require at least 3 inliers in best model, else fail.
    // ecx here = [rsp+0x20] = bestCnt (loaded at 0x18000763e on last pass)
    // =========================================================================
    if (bestCnt < 3) goto L_done_zero;    // cmp ecx,3; jl 0x1800077b4         // 0x180007684/87

    // ---- rebuild minimal model from the WINNING pair (best_i, best_j) ----
    rdx = (int64)best_j;  rcx = (int64)best_i;   // movsxd (signed)            // 0x18000768d/90
    r8 = &[rsp+0x48];
    [rsp+0x60] = A[best_j];   // rsi+rdx*8                                     // 0x180007698/9c
    [rsp+0x68] = A[best_i];   // rsi+rcx*8                                     // 0x1800076a1/a5
    [rsp+0x48] = B[best_j];   // rdi+rdx*8                                     // 0x1800076aa/b3
    rdx = &[rsp+0x60];
    [rsp+0x50] = B[best_i];   // rdi+rcx*8                                     // 0x1800076b8/bf
    rcx = ctx_fit2(r9);
    ok = sub_180007390(rcx, rdx, r8);     // rebuild 4-dword (a,b,tx,ty)       // 0x1800076c4
    if (!ok) goto L_done_zero;            // je 0x1800077b4                    // 0x1800076c9/cb

    // ---- gather consensus set: re-test every k, copy inliers into 3 buffers ----
    r13 = outB    = [rsp+0x100];                                              // 0x1800076d1
    r12 = outA_y  = [rsp+0xf8];                                              // 0x1800076d9
    rbp = outA_x  = [rsp+0xf0];                                              // 0x1800076e1
    r14 = B(home c0);                                                         // 0x1800076e9
    rdi = 0; (r13'-base): r12 -= r13 (delta outB - outA_y)                    // 0x1800076f1..f6
    r13 = ctx(home b0);  rax = A(home b8);                                    // 0x1800076f9/705
    int m = 0;            // esi = #consensus written                         // 0x180007701
    int k = 0;            // ebx                                              // 0x180007703

  L_gather:                                                                   // 0x180007710
    // apply best model to A[k]
    rcx=&[rsp+0x30]; r8=ctx(r13); rdx = &A[k](rax);                          // 0x180007710..18
    sub_180007450(&[rsp+0x30], &A[k], ctx);                                  // 0x18000771b
    int gx = [rsp+0x30];  int gy = [rsp+0x34];                                // 0x180007720/25
    gy -= *(int*)(r14+4);  // - B[k].y                                        // 0x180007729
    gx -= *(int*)(r14);    // - B[k].x                                        // 0x18000772d
    int gresid = gy*gy + gx*gx;                                              // 0x180007730..37
    if (gresid <= threshSq) {             // jg 0x180007766                    // 0x18000773a/41
        // append correspondence k to consensus buffers
        rax_delta = [rsp+0x38];           // = A-B ptr delta                   // 0x180007743
        rdi += 8;  m++;                                                       // 0x180007748/4c
        outA_y_slot = *(qword*)(r14 + (A-B));  // = A[k]                       // 0x18000774f
        *(qword*)(r12 + rdi - 8) = A[k];  // store A[k] into outA_y stream     // 0x180007757
        *(qword*)(rdi - 8)       = B[k];  // store B[k] into outA_x stream     // 0x18000775c/5f
        *(int*)(rbp - 4)         = k;     // store original index k            // 0x180007763
    }
  L_gather_next:                                                              // 0x180007766
    rax = A-ptr(home b8) advance;                                            // 0x180007766
    k++;  r14 += 8;  rax += 8;                                               // 0x18000776e..75
    [rsp+0xb8] = rax;                                                         // 0x18000777c
    if (k < N) goto L_gather;             // jl 0x180007710                    // 0x180007779/84

    // ---- least-squares refine over the m consensus correspondences ----
    // sub_1800073f0(ctx, outA_y_base, outB_base, m)
    r8  = outB    = [rsp+0x100];                                             // 0x180007786
    rdx = outA_y  = [rsp+0xf8];                                              // 0x18000778e
    rcx = ctx(home b0);                                                       // 0x180007796
    r9d = m;                                                                  // 0x18000779e
    ok = sub_1800073f0(rcx, rdx, r8, m);  // LSQ similarity refit (Q16)        // 0x1800077a1
    if (!ok) m = 0;                       // cmove esi,0                       // 0x1800077a6..ad
    eax = m;                                                                  // 0x1800077b0
    goto L_ret;                           // jmp 0x1800077b6                   // 0x1800077b2

L_done_zero:                              // (also L_done_zero_check / fail)   // 0x1800077b4
    eax = 0;
L_ret:                                                                        // 0x1800077b6
    rbx = [rsp+0xc8];   // restore saved rbx                                   // 0x1800077b6
    // epilogue: add rsp,0x70; pop r15..rbp                                    // 0x1800077be
    return eax;                                                               // 0x1800077cd
}
```

### Notes / caveats on the inner-loop pointer arithmetic
- `r11 = A - B` is a *byte* pointer delta; `*(qword*)(r10 + r11)` with `r10 = &B[i]`
  yields `A[i]`, and `*(qword*)(r11 + r13)` with `r13 = &B[j]` yields `A[j]`. This is
  the disassembler's way of indexing A relative to B with one base register.
- The 8-byte "point" is copied as a qword (`[rsp+0x60]/[rsp+0x68]/[rsp+0x48]/[rsp+0x50]`)
  but the helpers read it as two `int32` `(x,y)`.
- The `r8/r14` "Aout" pointers (arg6) stride +4/+8 and are read as the source `(cx,dx)`
  used only for the `|cx-dx|>16` pruning gate. Their precise semantic role (likely a
  per-point scalar such as orientation or a y-coordinate guard) is **inferred** — they
  feed only the prune test, not the transform math.

### Magic constants
- `0xffffffff` (−1) — sentinel "no best pair yet" for best_i / best_j.
- `0x10` (16) — prune threshold on `|cx-dx|`; pairs whose guard scalars differ by
  more than 16 are skipped (rejects implausible correspondences cheaply).
- `0x3` — minimum inlier count required to attempt the LSQ refit (2-pt model + ≥1 more).
- Q16 fixed-point arithmetic is performed inside the helpers (see callees), not here;
  this function works in raw integer pixel space for the residual test
  (`resid = dx*dx + dy*dy`, both already post-`>>16` rounded by `sub_180006bc0`).

## Callees
- `0x180007390` — minimal **2-point similarity solver** wrapper; calls `sub_180006e10`
  (2-point rigid Q16 solve, divisor = `isqrt(baseline²)`) and packs 4 dwords
  `(a, b, tx, ty)` into the 16-byte out-struct. See `func_180007390.md`.
- `0x180007450` — **apply Q16 transform to a point** wrapper; calls `sub_180006bc0`
  (`out = (R·p + t + 0x8000) >> 16`). Used to map A[k] into B-space for the
  residual test. See `func_180007450.md`.
- `0x1800073f0` — **least-squares similarity refit** wrapper over the consensus set;
  calls `sub_180006f20` (accumulate sums/centroids/cross-products, solve, Q16 output).
  See `func_1800073f0.md`.

(Indirect, for porters: `sub_180006e10`, `sub_180006bc0`, `sub_180006f20`,
`sub_180006c40`, and `sub_180003060` = integer sqrt — all documented in this dir.)

## GDB verification hooks

Set `break *0x<addr>` (the .dll is loaded under Wine; rebase by adding the module
base to these RVAs as usual). Suggested probes to validate a Python re-implementation,
in execution order:

1. **`break *0x180007480`** (entry) — dump args:
   - `rcx`=ctx_fit2, `rdx`=A, `r8`=B, `r9`=ctx_apply.
   - `*(int*)($rsp+0xe0)` = N, `*(int*)($rsp+0xe8)` = threshSq, and the three output
     buffer ptrs at `$rsp+0xf0 / 0xf8 / 0x100`. Confirms the calling contract.

2. **`break *0x18000756a`** (just before the minimal solver in the search loop):
   - `x/2dw $rsp+0x60` = source pt #1 (A[i]), `x/2dw $rsp+0x68`? — note at this site
     only `[rsp+0x60]` (A[i]) and `[rsp+0x48]` (B[i]) and `[rsp+0x50]` (B[j]) are set;
     A[j] is at `[rsp+0x68]`. Dump `x/2dw $rsp+0x48`, `x/2dw $rsp+0x50`,
     `x/2dw $rsp+0x60`, `x/2dw $rsp+0x68` to capture the 2 correspondences fed in.

3. **`break *0x180007571`** (right after solver returns) — `info reg eax` (ok flag),
   then `x/4dw $rsp+0x30` is **not** the model here; the model 4 dwords were written by
   `sub_180007390` into the 16-byte struct whose ptr was `rbx` inside that callee
   (i.e. the caller's `[rsp+0x30]`-region per the apply path). Best to hook the solver
   itself (see `func_180007390.md` hook at `0x1800073c4`) to capture `(a,b,tx,ty)`.

4. **`break *0x1800075b9`** (residual compare, in the inlier-count loop) — the key math:
   - `eax` = `resid = dx*dx + dy*dy` (transformed-A[k] minus B[k]); compared to
     `*(int*)($rsp+0xe8)` = threshSq. Dump `eax` and `[rsp+0x30]/[rsp+0x34]`
     (transformed point) and `*(2dw)$rdi` (B[k]) to verify residuals byte-for-byte.

5. **`break *0x1800075c2`** — taken only when a point is accepted; watch `ebx` (running
   inlier count `inl`) increment.

6. **`break *0x18000760e`** (best-update) — `[rsp+0x20]`←`inl`; dump `ebx`(inl),
   `ebp`(new best_j=i), `r12d`(new best_i=j). Confirms the argmax-over-pairs selection.

7. **`break *0x180007684`** — `ecx` = final `bestCnt`; verifies the ≥3 gate.

8. **`break *0x1800076c4`** (refit-model rebuild from winning pair) — dump
   `x/2dw $rsp+0x48`,`+0x50`,`+0x60`,`+0x68` = the two winning correspondences
   (B[best_j],B[best_i],A[best_j],A[best_i]).

9. **`break *0x18000773a`** (consensus residual) — `eax`=gresid vs threshSq; and at
   **`0x180007757`/`0x18000775f`/`0x180007763`** dump the stores: `A[k]`→outA_y stream,
   `B[k]`→outA_x stream, `k`(`ebx`)→index stream, with `esi`=running consensus count `m`.

10. **`break *0x1800077a1`** (LSQ refit call) — `rcx`=ctx, `rdx`=outA_y base,
    `r8`=outB base, `r9d`=`m`. Hook `sub_1800073f0`'s store site (`0x180007424` etc,
    see `func_1800073f0.md`) to capture the **final refined `(a,b,tx,ty)`** —
    this is the transform that reaches `sec0_pre`.

11. **`break *0x1800077b0`** (return) — `eax` = returned inlier count (0 if refit failed
    via the `cmove` at `0x1800077ad`).

## Confidence & open questions

**Solid (high confidence):**
- Overall algorithm = exhaustive-pair RANSAC for a 2-point similarity model + inlier
  count + ≥3-inlier gate + least-squares refit on the consensus set. The two nested
  loops, the `dx*dx+dy*dy ≤ threshSq` residual test, the argmax-keep-best, and the
  three callee roles are unambiguous from the disasm and the already-documented callees.
- Return value = inlier count of the refined model (0 on failure / <3).
- The `0x10`/`0x3` constants and the −1 sentinels.
- Points are 8-byte `(int32 x, int32 y)` records.

**Inferred (medium):**
- The exact semantic of `arg6`/`Aout` (`[rsp+0xd8]`) — it provides the `(cx,dx)`
  scalars used **only** by the `|cx-dx|>16` pruning gate. Likely a per-keypoint guard
  (orientation bucket or a coordinate band) to avoid pairing far-apart points; it does
  not enter the transform fit. Worth confirming with hook #4's surrounding context.
- The naming of the three consensus output buffers `outA_x/outA_y/outB` and which
  receives A vs B — based on the store pattern at `0x180007757..0x180007763`; the LSQ
  refit consumes `outA_y` (rdx) and `outB` (r8). Direction (A→B vs B→A) is consistent
  with the apply step mapping A[k] into B-space, but verify with hook #10 + the refit doc.

**Open questions:**
- `arg5` (`[rsp+0xd0]`) is never directly referenced in this body (only the home-space
  slots 0xb0/0xb8/0xc0 are). It may be padding in the numbering or consumed only by the
  caller; treat as unused here.
- Whether the search is intended to be full C(N,2) or whether the `>16` gate is expected
  to prune most pairs in practice (affects performance but not correctness of a port).
