# sub_180003ea0 — per-frame byte-array statistics: sum / filtered-average / median / overall-average

This 361-byte, 103-instruction function is a **statistics aggregator over a byte array**, NOT a transform/matrix routine. It contains **no** fixed-point (`>>16`, `*0x10000`, `0x8000`-rounding), **no** trig/sqrt, and **no** affine math. The only "math" is integer accumulation and two signed `idiv` averages (with a `0x7fff` saturation fallback when the divisor count is `<= 0`).

Its role in the geometry pipeline is *upstream bookkeeping*: it summarises a per-element byte metric (most plausibly per-keypoint / per-correspondence **quality or score** bytes) into four scalar outputs — total sum, average, median, and a filtered average — and optionally first runs the correspondence-table setup helper `sub_180003d30`. These scalars are the kind of per-frame summary that downstream code (the actual rigid-transform / Hough-voting stages) reads to gate or weight a frame. So: relevant *context* for sec0_pre, but this specific function does not itself compute any transform.

Caller: `sub_1800043d0` (per call graph). Callees: `sub_180003d30` (table init) and `sub_1800095c0` (generic introsort).

## Signature

15 arguments (4 register + 11 stack). Offsets below are *entry-relative* (before the prologue's 5 pushes + `sub rsp,0x40` = 0x68 byte shift; e.g. post-prologue `[rsp+0xc8]` == entry `[rsp+0x60]`).

```c
// Returns nothing (void). All results are written through output pointers.
void sub_180003ea0(
    int32_t*  outSumThenAvg,   // rcx        (arg1) -> zeroed, then = sum(data[0..N)), finally overwritten with sum/N (overall average)
    void*     doMedian,        // rdx        (arg2) -> if non-NULL: sort data[] and write median to *(int*)outMedian
    uint8_t*  filterTable,     // r8         (arg3) -> if non-NULL: 256-ish-entry byte map; entry==0 => element is INCLUDED in filtered avg
    int32_t*  outFilteredAvg,  // r9         (arg4) -> filtered average destination (sum of included values / includedCount, else 0x7fff)
    void*     srcA_data,       // [rsp+0x28] (arg5)  -> forwarded to sub_180003d30 as r8  (source list A)        [GUESS: list_t*]
    void*     srcB_data,       // [rsp+0x30] (arg6)  -> forwarded to sub_180003d30 as r9  (source list B)        [GUESS: list_t*]
    /* arg7 [rsp+0x38], arg8 [rsp+0x40] : not referenced directly here */
    void*     dstB_table,      // [rsp+0x48] (arg9)  == rbp == DATA ARRAY base (the byte array all stats run over). NOTE reused name; see notes.
    void*     keysA,           // [rsp+0x50] (arg10) -> forwarded to sub_180003d30 stack arg (pairCount byte array A)  [GUESS]
    uint8_t*  catBytes,        // [rsp+0x58] (arg11) == r12 -> per-element CATEGORY/key byte array (parallel to data[]); indexes filterTable
    int32_t   N,               // [rsp+0x60] (arg12) == r13 (movsxd, SIGNED) -> element count of data[]/catBytes[]
    int32_t*  outFilteredCnt,  // [rsp+0x68] (arg13) -> filtered-include counter (incremented; also used as the divisor)
    list_t*   srcListA,        // [rsp+0x70] (arg14) -> if non-NULL (and srcListB non-NULL): triggers sub_180003d30 call (rcx)
    list_t*   srcListB         // [rsp+0x78] (arg15) -> second guard / sub_180003d30 arg (rdx)
);
```

Notes / cautions:
- `outMedian` (arg2 / rdx) is passed as a generic pointer in the call but dereferenced as `int32_t*` when the median is stored (`mov [r15],eax`).
- The DATA array that every statistic iterates is `rbp = [rsp+0x48]` (arg9). The same value is also re-used as `srcA`-style content forwarded into `sub_180003d30` (it is passed as `[rsp+0x30]` to that helper inside block A). The "dstB_table"/"keys" naming is **inferred** by analogy to `sub_180003d30`'s documented layout and is a *guess*; what is *solid* is that `rbp` is the byte buffer that is summed, sorted, and median-sampled.
- `filterTable[byte]==0 => include`: matches `sub_180003d30`, which seeds selected slots with `0xff`. So `0xff` (or any non-zero) = "excluded/flagged"; `0` = "kept".
- `0x7fff` (32767) is the saturation sentinel written to an average output whenever its divisor (`N` or `includedCount`) is `<= 0`.

## Pseudocode

```c
void sub_180003ea0(int *outSumThenAvg /*rcx->rdi*/, void *doMedian /*rdx->r15*/,
                   u8 *filterTable /*r8->r14*/, int *outFilteredAvg /*r9->rsi*/, ...)
{
    // ---- prologue: save rbx,rbp,rsi into home slots; push rdi,r12..r15; sub rsp,0x40 ----  // 0x180003ea0..0x180003eb8

    int   N        = (int)*(int32_t*)[rsp+0xc8];   // r13 = movsxd arg12 (SIGNED element count)   // 0x180003ebc
    void *arg11    = *(void**)[rsp+0xc0];           // r12 (catBytes / per-element category array) // 0x180003ec4

    int rbx = 0;                                                                                   // 0x180003ecc xor ebx,ebx
    *(int*)rcx = 0;            // *outSumThenAvg = 0   (zero the primary accumulator)              // 0x180003ece mov [rcx],ebx
    void *rdi  = rcx;          // rdi = outSumThenAvg                                              // 0x180003ed0

    void *guard1 = *(void**)[rsp+0xd8];   // arg14 (srcListA)                                      // 0x180003ed3
    void *rsi    = r9;         // rsi = outFilteredAvg                                             // 0x180003ede
    void *r14    = r8;         // r14 = filterTable                                                // 0x180003ee1
    void *r15    = rdx;        // r15 = doMedian                                                   // 0x180003ee4
    if (guard1 == NULL) goto L_skipInit;                                                          // 0x180003ee7 je 0x180003f22

    void *guard2 = *(void**)[rsp+0xe0];   // arg15 (srcListB)                                      // 0x180003ee9
    if (guard2 == NULL) goto L_skipInit;                                                          // 0x180003ef4 je 0x180003f22

    // ---- BLOCK A: optional correspondence-table init ----                                       // 0x180003ef6
    //   sub_180003d30(rcx=guard1, rdx=guard2, r8=arg5, r9=arg6,
    //                 [rsp+0x20]=N, [rsp+0x28]=arg10, [rsp+0x30]=arg11)
    {                                                                                              // 0x180003ef6..0x180003f18 marshal stack args
        void *rax = *(void**)[rsp+0xb8];          // arg10 (keysA)                                 // 0x180003ef6
        void *r9_ = *(void**)[rsp+0x98];          // arg6  (srcB_data)                             // 0x180003efe
        void *r8_ = *(void**)[rsp+0x90];          // arg5  (srcA_data)                             // 0x180003f06
        [rsp+0x30] = arg11;   // r12                                                               // 0x180003f0e
        [rsp+0x28] = rax;     // arg10                                                             // 0x180003f13
        [rsp+0x20] = N;       // r13d                                                              // 0x180003f18
        sub_180003d30(guard1, guard2, r8_, r9_ /*, N, arg10, arg11*/);                             // 0x180003f1d call 0x180003d30
    }

L_skipInit:                                                                                        // 0x180003f22
    void *rbp = *(void**)[rsp+0xb0];   // rbp = DATA ARRAY base (arg9)                              // 0x180003f25
    long rdx = N;                       // rdx = loop count copy                                   // 0x180003f2d
    if (N <= 0) goto L_afterSum;                                                                   // 0x180003f30 jle 0x180003f4f

    // ---- BLOCK B: total sum over all N bytes ----                                                // 0x180003f40 (16-byte aligned loop)
    for (rbx = 0; rbx < N; rbx++) {                                                                // 0x180003f4a/0x180003f4d
        u8 v = data[rbx];          // movzx [rbx+rbp]                                              // 0x180003f40
        *(int*)rdi += v;           // *outSumThenAvg += v                                          // 0x180003f48 add [rdi],eax
    }

L_afterSum:                                                                                        // 0x180003f4f
    if (filterTable == NULL) goto L_median;   // r14==0                                            // 0x180003f4f/0x180003f52
    {
        int *r8 = *(int**)[rsp+0xd0];   // arg13 = outFilteredCnt (counter/divisor)                // 0x180003f57
        if (N <= 0) goto L_filtDiv;                                                                // 0x180003f5f jle 0x180003f8f

        // ---- BLOCK C: filtered sum (include element i iff filterTable[catBytes[i]]==0) ----
        void *rcx = rbp;                 // value cursor over data[]                               // 0x180003f61
        arg11 -= rbp;   // r12 = catBytes - data  (so [r12+rcx] == catBytes[i])                    // 0x180003f64 sub r12,rbp
        long rdx2 = N;
        do {                                                                                       // 0x180003f70 (loop top)
            u8 cat = *(u8*)(arg11 + rcx);     // catBytes[i]                                       // 0x180003f70 movzx [r12+rcx]
            if (filterTable[cat] != 0) goto next;  // excluded                                     // 0x180003f75 cmp [rax+r14],0 ; 0x180003f7a jne
            (*r8)++;                          // includedCount++ (*outFilteredCnt)                 // 0x180003f7c add [r8],1
            *(int*)rsi += *(u8*)rcx;          // *outFilteredAvg += data[i]                        // 0x180003f80/0x180003f83
        next:
            rcx += 1;                                                                              // 0x180003f85
        } while (--rdx2 != 0);                                                                     // 0x180003f89/0x180003f8d

L_filtDiv:                                                                                         // 0x180003f8f
        int cnt = *r8;                                                                             // 0x180003f8f
        if (cnt > 0) {                                                                             // 0x180003f92/0x180003f94
            *(int*)rsi = (int)*(int*)rsi / cnt;   // signed idiv: filtered average                 // 0x180003f96..0x180003f9b
            goto L_median;                                                                          // 0x180003f9d
        }
        *(int*)rsi = 0x7fff;   // 32767 saturation (no included elements)                          // 0x180003f9f
    }

L_median:                                                                                          // 0x180003fa5
    if (doMedian == NULL) goto L_overallAvg;   // r15==0                                           // 0x180003fa5/0x180003fa8
    {
        // ---- BLOCK D: sort data[] in place, then take the middle element ----
        // qsort(base=rbp, count=N, elemSize=1, cmp=0x180003480)
        r9  = 0x180003480;   // comparator                                                         // 0x180003faa lea r9,[rip+...]
        r8d = 1;             // element size = 1 byte                                              // 0x180003fb1
        edx = N;             // count                                                              // 0x180003fb7
        rcx = rbp;           // base                                                               // 0x180003fba
        sub_1800095c0(rbp, N, 1, 0x180003480);   // generic introsort                              // 0x180003fbd call 0x1800095c0

        int t  = N - 1;                                                                            // 0x180003fc2 lea eax,[r13-1]
        // signed floor-div-by-2 of (N-1): (t - (t>>31)) >> 1 == (N-1)/2 toward zero
        t = (t - (t < 0 ? -1 : 0)) >> 1;          // cdq; sub eax,edx; sar eax,1                   // 0x180003fc6..0x180003fc9
        long mid = (int)t;                         // movsxd                                       // 0x180003fcb
        *(int*)r15 = data_sorted[mid];   // *outMedian = sorted[(N-1)/2]                            // 0x180003fce/0x180003fd2
    }

L_overallAvg:                                                                                      // 0x180003fd5
    // ---- BLOCK E: overall average = totalSum / N (or 0x7fff) ----
    if (N <= 0) {                                                                                  // 0x180003fd5/0x180003fd8
        *(int*)rdi = 0x7fff;                                                                       // 0x180003fe4
    } else {
        *(int*)rdi = (int)*(int*)rdi / N;   // signed idiv: overall average                        // 0x180003fda..0x180003fe0
    }

    // ---- epilogue: restore rbx,rbp,rsi; add rsp,0x40; pop r15..rdi; ret ----                     // 0x180003fea..0x180004009
}
```

Order of side-effects (important for a faithful port):
1. `*outSumThenAvg = 0` (always).
2. Optional `sub_180003d30(...)` table init (only if both `srcListA` and `srcListB` non-NULL).
3. `*outSumThenAvg = Σ data[i]` (the running sum).
4. If `filterTable != NULL`: compute `*outFilteredAvg = (Σ data[i] over included) / *outFilteredCnt`, saturate to `0x7fff` if count `<= 0`. (`*outFilteredAvg` and `*outFilteredCnt` are assumed pre-zeroed by the caller — this function only `+=`/`++`s them.)
5. If `doMedian != NULL`: sort `data[]` in place and `*outMedian = sorted[(N-1)/2]`.
6. `*outSumThenAvg = sum / N` (overwrites the sum with the overall average), saturate to `0x7fff` if `N <= 0`.

CAUTION on step 5 vs 3/4: the sort in block D **mutates `data[]` in place**. Because the overall-sum (block B) and filtered-sum (block C) both run *before* the sort, they see the original (unsorted) data — order is irrelevant to a sum, so this is fine. But any external code holding `data[]` after this call gets it sorted.

Magic constants:
- `0x7fff` (32767) — saturation sentinel when an average's divisor `<= 0` (written to `*outFilteredAvg` and/or `*outSumThenAvg`). Looks like a max-i16 "invalid / worst" placeholder.
- `1` — element size passed to the sort (byte array).
- `0x180003480` — sort comparator function pointer (byte comparator; the standard `{key,index}` style introsort comparator used elsewhere in this DLL).
- `(N-1)/2` — median index (signed floor toward zero via `cdq;sub;sar 1`). For even N this is the *lower* of the two middle elements (true median-low, no averaging).

## Callees

- `0x180003d30` — correspondence/feature-table init: builds two `{u32 index,u64 payload}` lookup tables and seeds byte-keyed sparse maps from two source lists. See `transformation-doc/func_180003d30.md`. (Called only when both `srcListA` and `srcListB` are non-NULL.)
- `0x1800095c0` — generic introsort / `qsort`-style sort (677 instrs, used throughout the DLL; comparator passed in r9). Here: `sort(base=data, count=N, elemSize=1, cmp=0x180003480)`. See `PACKER-sub_180002240.md` and `SCORER-sub_18000c6a0.md` for prior decode of this sort.
- `0x180003480` — (not a call target; passed as the comparator pointer) byte comparator for the sort. Decode separately if exact ordering/tiebreak matters (`func_180003480.md` — not yet written).

## GDB verification hooks

To verify a Python re-implementation produces identical intermediate values, set breakpoints and dump as follows (process under Wine; use `scripts/gdb_dump.py` per project memory):

- **`break *0x180003ebc`** (entry): dump the arguments.
  - `r13` after the `movsxd` (or read `*(int*)($rsp+0xc8)` *before* it executes) = `N`.
  - `*(void**)($rsp+0xb0)` = `data[]` base (arg9). Dump `x/<N>bx <that ptr>` to capture the RAW (unsorted) input bytes — capture this BEFORE block D sorts them.
  - `*(void**)($rsp+0xc0)` = `catBytes` base (arg11); `$r8` (arg3) = `filterTable` base.
  - `*(void**)($rsp+0xd8)`,`*(void**)($rsp+0xe0)` = the two gate pointers (decide whether block A runs).

- **`break *0x180003f48`** (block B sum step): each hit, `$rbx` = i, `$eax` = `data[i]`, `*(int*)$rdi` = running sum *before* this add. Lets you reproduce the sum byte-by-byte.

- **`break *0x180003f8f`** (after filtered loop): `*(int*)$r8` = includedCount, `*(int*)$rsi` = filtered SUM (pre-division). This is the cleanest single check for block C — compare your `includedCount` and `filteredSum`.

- **`break *0x180003f9b`** (`mov [rsi],eax`): `$eax` = the final **filtered average** written to `*outFilteredAvg`. (Or `break *0x180003f9f` to catch the `0x7fff` saturation path.)

- **`break *0x180003fbd`** (just before the sort): confirm `$rcx`=base, `$edx`=N, `$r8d`=1, `$r9`=0x180003480. Re-dump `x/<N>bx $rcx` here for the pre-sort array; dump again at the next line to see the sorted result.

- **`break *0x180003fce`** then read `$ecx` (= median index `(N-1)/2`) and **`break *0x180003fd2`** read `$eax` = the **median value** written to `*outMedian` (`*(int*)$r15`).

- **`break *0x180003fe0`** (`mov [rdi],eax`): `$eax` = the **overall average** = sum/N written to `*outSumThenAvg`. (`break *0x180003fe4` for the `0x7fff` path.)

Priority order for cross-checking the port: 0x180003f8f (filtered sum+count) → 0x180003f9b (filtered avg) → 0x180003fd2 (median) → 0x180003fe0 (overall avg).

## Confidence & open questions

Solid (directly from disasm):
- The four outputs and their formulas: `*outSumThenAvg` = Σ then Σ/N; `*outFilteredAvg` = filteredΣ/filteredCnt; `*outMedian` = sorted[(N-1)/2]; the `0x7fff` saturation on `count<=0`.
- The inclusion predicate `filterTable[catBytes[i]] == 0`.
- The in-place sort of `data[]` with element size 1 and comparator `0x180003480`; median index `(N-1)/2` (signed floor).
- `N` is signed (`movsxd`); both divisions are signed (`cdq;idiv`).
- Order of operations / side-effect sequence (sum and filtered-sum read unsorted data; sort happens after).

Inferred / guessed:
- **Semantic meaning of the data bytes** — most consistent reading is per-keypoint/per-correspondence **quality or match-score** bytes, with `catBytes` a per-element category (e.g. tile id / class) and `filterTable` a "which categories to exclude" map. This is *not provable from this function alone* — it depends on what `sub_1800043d0` passes. NOT a transform.
- The argument names for the `sub_180003d30` forwarders (arg5,6,10) follow that helper's documented layout; treated as a guess here.
- That the caller pre-zeroes `*outFilteredAvg` and `*outFilteredCnt` (this function only accumulates into them). Verify by hooking the caller `sub_1800043d0`.

Open questions:
- Exact tiebreak/order semantics of comparator `0x180003480` (matters only for even-N median selection if duplicate values straddle the midpoint — for a pure byte sort the median *value* is order-independent, so likely irrelevant). Decode `func_180003480.md` if a discrepancy appears.
- Whether `data[]`, `catBytes[]`, and the `sub_180003d30` source lists are the same physical buffer at different offsets (the `rbp`/forwarded-arg overlap hints the caller packs them into one structure). Confirm from `sub_1800043d0`.
- This function performs **no** rigid-transform / Q16 / trig / voting math; it is a statistics pre-pass. For sec0_pre transform math, look to sibling functions (`sub_180003b50`, etc.), not here.
