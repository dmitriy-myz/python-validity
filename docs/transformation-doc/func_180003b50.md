# sub_180003b50 — build a per-cell occupancy/coverage grid, sort it, derive a threshold count and a 5-bucket level histogram

This function rasterises a set of keypoints into a `W x H` byte grid (`W = arg4`, `H = arg5`),
where each keypoint paints a small box of a per-keypoint "level" byte (via the leaf rasteriser
`sub_180003a00`). The grid is initialised to `0x80` ("empty" sentinel). After painting it
**sorts the whole grid as a flat byte array ascending** (libc-style `qsort` at `0x1800095c0`
with a byte comparator at `0x180003480`), then:

1. counts how many trailing cells are still `0x80` (never painted) to get the number of *filled*
   cells `r11d` (the "occupied area" / population), and
2. classifies that population into a small **5-entry decision table** seeded with the bytes
   `0x11,0x21,0x31,0x41,0x51` (these look like packed `(level<<4 | tag)` thresholds), writing the
   chosen level into `*(int*)rcx` for the first 4 entries that fail an interval test, then a final
   compaction pass.

The output written through `arg1` (`rsi`) is a single `int`: either `0` (no cells filled) or the
table's `[+0xc]` slot (the resolved level). The `int[5]` work-table itself lives at `[rsp+0x40]`
and is returned through the out-pointer in `[rsp+0xa8]`/`[rsp+0xa0]` (set up before the qsort).

This is **not** rigid/similarity-transform math: no Q16 fixed-point, no `>>16`/`0x10000`/`0x8000`,
no trig, no matrix. It is integer **binning / coverage scoring** — a quality/coverage metric over
the keypoint cloud, the kind of value that feeds *whether* a frame is good enough to register, not
the transform itself. Recorded for completeness of the sec0_pre call-graph sweep.

## Signature

Windows x64. Four register args + several stack args. Types are best-effort.

```c
// GUESS on most types; the (W,H,grid,keypoints) and the qsort/threshold shape are solid.
int sub_180003b50(
    int      *out_level,     // rcx  -> result int (level), set to 0 then overwritten at end
    void     *arg1_rdx,      // rdx  : saved to [rsp+0x10]; only relayed, role unclear (GUESS: ctx)
    int       arg2_r8d,      // r8d  : (unused after spill?) — see open questions
    void    **kp_base_pp,    // r9   : ptr to ptr -> keypoint struct array (deref'd once: *r9)
    // ---- stack args (after 0x20 shadow) ----
    uint8_t   width,         // [rsp+0xc0]  -> r12d  : grid width  W
    uint8_t   height,        // [rsp+0xc8]  -> r13d  : grid height H   (W*H = grid cell count)
    void     *grid_out,      // [rsp+0xd0]  : (also) source array A for inner-call arg0 (idx bytes)
    void     *src_B,         // [rsp+0xe0]  : source array B for inner-call arg2 (fill/level bytes)
    int       n_keypoints,   // [rsp+0xe8]  : element count for the paint loop (0 => skip painting)
    void     *out_table5,    // [rsp+0xa0]/[rsp+0xa8] : out ptr -> int[5] decision table (=&[rsp+0x40])
    uint8_t  *grid           // [rsp+0xf0]  -> rbp   : the W*H byte grid buffer (filled, sorted)
);
// returns int (eax) = the resolved level: 0 if nothing filled, else table[3] (=[rdi+0xc]).
```

Notes / cautions:
- The stack-arg offsets above are *post-prologue* (after `push`×7 + `sub rsp,0x60`, the home area
  shifts). The function reads them as `[rsp+0xc0]`, `[rsp+0xc8]`, `[rsp+0xd0]`, `[rsp+0xe0]`,
  `[rsp+0xe8]`, `[rsp+0xf0]`, `[rsp+0xa0]`, `[rsp+0xa8]`, `[rsp+0xb0]` — these are the *caller's*
  argument slots / out-params, not locals.
- `[rsp+0xa8]`→`rdi` and `[rsp+0xa0]`→`rsi` are loaded **only on the no-paint path** (`je`), but the
  table-write code uses `rdi`/`rsi` afterwards regardless — so on the paint path `rdi`/`rsi` carry
  over from the inner loop. See open questions; this is a compiler tail-merge of two predecessors.

## Pseudocode

```c
int sub_180003b50(int *out_level /*rcx*/, void *rdx, int r8d, void **kp_base_pp /*r9*/, ...)
{
    // ---- prologue: mov rax,rsp; home rcx/rdx/rbx; push rbp,rsi,rdi,r12..r15; sub rsp,0x60 ----
    //                                                                          // 0x180003b50..0x180003b6a
    //   [rax+0x08]=rcx(saved), [rax+0x10]=rdx(saved), [rax+0x18]=rbx(saved)    // 0x180003b53..0x180003b5b

    uint32_t W  = *(uint8_t*)(rsp + 0xc0);          // r12d  grid width         // 0x180003b6e
    uint32_t H  = *(uint8_t*)(rsp + 0xc8);          // r13d  grid height        // 0x180003b77
    uint8_t *grid = *(uint8_t**)(rsp + 0xf0);       // rbp   grid buffer        // 0x180003b80
    void    *rdi_save = rdx;                        // rdi = rdx (arg1)         // 0x180003b88
    int     *rsi_out  = (int*)out_level;            // rsi = rcx (arg0/out)     // 0x180003b8b
    uint32_t cells_dup = W;                         // r15d = r12d              // 0x180003b8e
    uint8_t  dl = 0x80;                             // dl = 0x80 (fill value)   // 0x180003b91  (mset val)
    void    *rbp_grid = grid;                       // rcx = rbp                // 0x180003b93
    void   **r14 = kp_base_pp;                      // r14 = r9 (arg3)          // 0x180003b96
    uint32_t cells = W * H;                         // r15d = r12d * r13d       // 0x180003b99  (grid cell count)
    uint32_t r8_cells = cells;                      // r8d = r15d               // 0x180003b9d

    // ---- seed the 5-entry decision table at [rsp+0x40] (rax-0x58 == rsp+0x40 ... rsp+0x50) ----
    *(int*)(rsp + 0x40) = 0x11;                      // [rax-0x58]              // 0x180003ba0
    *(int*)(rsp + 0x44) = 0x21;                      // [rax-0x54]              // 0x180003ba7
    *(int*)(rsp + 0x48) = 0x31;                      // [rax-0x50]              // 0x180003bae
    *(int*)(rsp + 0x4c) = 0x41;                      // [rax-0x4c]              // 0x180003bb5
    *(int*)(rsp + 0x50) = 0x51;                      // [rax-0x48]              // 0x180003bbc

    // ---- memset-like fill: grid[0 .. cells) = 0x80  (sub_1800031c0(grid,0x80,cells)) ----
    sub_1800031c0(/*rcx*/grid, /*dl=*/0x80, /*r8d=*/cells);                     // 0x180003bc3
    //   (sub_1800031c0 guards count>0, sign-extends, forwards to fill helper sub_1800e0a60)

    int n = *(int*)(rsp + 0xe8);                     // n_keypoints             // 0x180003bc8
    *(int*)rsi_out = 0;                              // *out_level = 0 (default)// 0x180003bcf
    if (n == 0) goto L_no_paint;                     // test eax; je 0x180003c32// 0x180003bd5..0x180003bd7

    // ---- PAINT LOOP: for each of n keypoints, splat a 5-px box of its level into the grid ----
    {
        uint8_t *A = *(uint8_t**)(rsp + 0xe0);       // rbx = src array A (idx bytes)   // 0x180003bd9
        uint8_t *B = *(uint8_t**)(rsp + 0xd0);       // rsi = src array B (fill/level)  // 0x180003be1
        uint64_t cnt = (uint64_t)(uint32_t)n;        // rdi = n (loop count)            // 0x180003be9
        int64_t  delta_BA = (uint8_t*)B - (uint8_t*)A; // rsi = B - A (index bias)      // 0x180003bec

        do {                                                                   // L_paint = 0x180003bf0
            void *kp_base = *r14;                    // rax = *r14 (keypoint struct base) // 0x180003bf0
            uint8_t fill  = *(uint8_t*)(A + delta_BA);// r8d = B[i]  (the "level" byte)    // 0x180003bf3
            uint8_t idx   = *(uint8_t*)A;            // ecx = A[i]  (keypoint index)       // 0x180003bf8
            // marshal stack args for the inner rasteriser:
            //   [rsp+0x30] = kp_base   (arg6: elem_base of 32-byte keypoint structs)     // 0x180003bfb
            //   r9b        = (uint8_t)W (arg3: width/stride)                              // 0x180003c00
            //   edx        = 5          (arg1: delta / half-extent of the box)            // 0x180003c04
            //   [rsp+0x28] = grid       (arg5: buf)                                       // 0x180003c09
            //   [rsp+0x20] = (uint8_t)H (arg4: height)                                    // 0x180003c0e
            sub_180003a00(/*idx*/idx, /*delta*/5, /*fill*/fill,
                          /*width*/(uint8_t)W, /*height*/(uint8_t)H,
                          /*buf*/grid, /*elem_base*/kp_base);                   // 0x180003c13
            A   += 1;                                 // add rbx,1                          // 0x180003c18
            cnt -= 1;                                  // sub rdi,1                          // 0x180003c1c
        } while (cnt != 0);                            // jne L_paint                       // 0x180003c20
        // NOTE: rdi/rsi are NOT reloaded on this path — they hold stale loop values
        //       (=0 and last B ptr). The table-write tail below uses rdi as the table ptr,
        //       which only works because on this path rdi was clobbered... see open questions.
        goto L_after;
    }

L_no_paint:                                                                    // 0x180003c32 target
    {
        // only reached when n==0; load the real out pointers
        // (these instructions sit at 0x180003c22/0x180003c2a, executed on the je fallthrough)
        rdi_save = *(void**)(rsp + 0xa8);            // rdi = out_table5 (int[5])          // 0x180003c22
        rsi_out  = *(int**) (rsp + 0xa0);            // rsi = out_level pointer            // 0x180003c2a
    }

L_after:                                                                       // 0x180003c32
    int ebx = 1;                                     // ebx = 1                            // 0x180003c32
    void *cmp = (void*)0x180003480;                  // r9 = &byte_cmp                     // 0x180003c37
    // ---- qsort(grid, num=cells, size=1, compar=byte_cmp_ascending) ----
    sub_1800095c0(/*base*/grid, /*size? r8d=*/1, /*num*/cells, /*compar*/cmp); // 0x180003c47
    //   sub_1800095c0 = generic qsort; comparator 0x180003480: return (int)a[0]-(int)b[0]

    // ---- count trailing 0x80 (== unfilled) cells, from the high end of the sorted array ----
    uint32_t r11 = cells - 1;                        // r11d = cells-1                     // 0x180003c4c
    int64_t  rax = (int32_t)r11;                     // movsxd (signed)                    // 0x180003c53
    if (r11 == 0) goto L_set_threshold_zero;         // test r11d; je 0x180003c71          // 0x180003c50..0x180003c56
    rax += (int64_t)grid;                            // rax = &grid[cells-1]               // 0x180003c58
    do {                                                                       // L_scan = 0x180003c60
        rax -= 1;                                     // rax = &grid[r11-1]  (sub rax,ebx=1)// 0x180003c60
        r11 -= 1;                                      // r11d += -1                        // 0x180003c63
        if (*(uint8_t*)rax != 0x80) goto L_have_count; // cmp [rax],0x80; jne 0x180003c75  // 0x180003c67..0x180003c6a
    } while (r11 != 0);                               // test r11d; jne L_scan             // 0x180003c6c..0x180003c6f
L_set_threshold_zero:                                                          // 0x180003c71
    r11 -= 1;                                          // r11d = -1 (== 0xffffffff)         // 0x180003c71
L_have_count:                                                                  // 0x180003c75
    // r11 now = (index of highest non-0x80 cell) == (#filled cells - 1), or -1 if none filled
    // cmp r11d,ebx(=1) sets flags for the jbe below                                       // 0x180003c75

    // ---- broadcast the count into all 5 table slots ----
    *(int*)(rdi_save + 0x00) = (int)r11;             // mov [rdi],   r11d                  // 0x180003c78
    *(int*)(rdi_save + 0x04) = (int)r11;             // mov [rdi+4], r11d                  // 0x180003c7b
    *(int*)(rdi_save + 0x08) = (int)r11;             // mov [rdi+8], r11d                  // 0x180003c7f
    *(int*)(rdi_save + 0x0c) = (int)r11;             // mov [rdi+0xc], r11d                // 0x180003c83
    *(int*)(rdi_save + 0x10) = (int)r11;             // mov [rdi+0x10],r11d                // 0x180003c87
    int *T = (int*)rdi_save;                         // T = table[5] (now all = r11)

    if ((uint32_t)r11 <= (uint32_t)1) goto L_compact; // jbe 0x180003cdd                   // 0x180003c8b

    // ---- CLASSIFY PASS: for level j=1..r11-1, test interval [seed[k-1] <= j < seed[k]] ----
    // seeds[] = the int[5] at [rsp+0x40] = {0x11,0x21,0x31,0x41,0x51}.
    // For each table slot k (0..4): if seed[k]<j  is false AND seed[k+? ] ... (see exact below)
    {
        int *seed = (int*)(rsp + 0x40);             // rcx walk base                       // 0x180003c8d
        int64_t Tbias = (uint8_t*)rdi_save - (uint8_t*)seed; // r10 = T - seed              // 0x180003c8d/0x180003c92/0x180003c99
        uint8_t *p8 = (uint8_t*)(grid + 1);          // r8 = &grid[1]  (sorted byte ptr)    // 0x180003c95
        int j = 1;                                    // ebx = 1 (outer loop level)          // (from L_after ebx=1)
        do {                                                                   // L_outer = 0x180003ca0
            int *c = (int*)(rsp + 0x40);             // rcx = seed base                     // 0x180003ca0
            int  k = 5;                               // r9d = 5 (inner count)               // 0x180003ca5
            do {                                                               // L_inner = 0x180003cb0
                int s = *c;                           // edx = seed[k']                      // 0x180003cb0
                uint8_t lo = *(uint8_t*)(p8 - 1);     // eax = grid[j-1]                     // 0x180003cb2
                if ((int)lo > s) goto L_inner_next;   // cmp lo,s; jg                        // 0x180003cb7..0x180003cb9
                uint8_t hi = *(uint8_t*)(p8);          // eax = grid[j]                       // 0x180003cbb
                if ((int)hi <= s) goto L_inner_next;   // cmp hi,s; jle                       // 0x180003cbf..0x180003cc1
                // here: grid[j-1] <= seed <  grid[j]  -> the seed lands in this gap → store j
                *(int*)((uint8_t*)c + Tbias) = j;     // T[k'] = j  (mov [r10+rcx],ebx)      // 0x180003cc3
            L_inner_next:
                c += 1;                                // rcx += 4                            // 0x180003cc7
                k -= 1;                                                                       // 0x180003ccb
            } while (k != 0);                          // jne L_inner                         // 0x180003ccf
            j  += 1;                                   // add ebx,1                           // 0x180003cd1
            p8 += 1;                                   // add r8,1                            // 0x180003cd4
        } while ((uint32_t)j < (uint32_t)r11);         // cmp ebx,r11d; jb L_outer            // 0x180003cd8..0x180003cdb
    }

L_compact:                                                                     // 0x180003cdd
    // ---- 4-step monotone fixup: for slot i=0..3, if T[i] > T[i+1] then T[i] = 0 ----
    {
        int *c = (int*)rdi_save;                     // rcx = T                             // 0x180003cdd
        int  cnt4 = 4;                                // r8d = 4                             // 0x180003ce0
        // r9d = 0 (zero const)                                                              // 0x180003ce6
        do {                                                                   // L_fix = 0x180003cf0
            int nxt = c[1];                           // eax = T[i+1]                        // 0x180003cf0
            if ((int)c[0] > nxt)                      // cmp T[i],eax; jle skip              // 0x180003cf3..0x180003cf5
                c[0] = 0;                             // T[i] = 0                            // 0x180003cf7
            c += 1;                                    // rcx += 4                            // 0x180003cfa
            cnt4 -= 1;                                                                        // 0x180003cfe
        } while (cnt4 != 0);                          // jne L_fix                           // 0x180003d02
    }

    // ---- write the result level out through rsi ----
    if (r11 == 0) {                                  // test r11d; jne 0x180003d0e          // 0x180003d04..0x180003d07
        *(int*)rsi_out = 0;                          // *out_level = 0   (mov [rsi],r9d=0)  // 0x180003d09
    } else {
        int v = *(int*)(rdi_save + 0x0c);            // eax = T[3]                          // 0x180003d0e
        *(int*)rsi_out = v;                          // *out_level = T[3]                   // 0x180003d11
    }

    // ---- epilogue: restore rbx, pop regs ----                                            // 0x180003d13
    rbx = *(uint64_t*)(rsp + 0xb0);                  // restore saved rbx                   // 0x180003d13
    // add rsp,0x60; pop r15,r14,r13,r12,rdi,rsi,rbp; ret
    return (int)/*eax*/ v_or_table;                  //                                     // 0x180003d1b..0x180003d2a
    // NOTE: eax on return = last value written ([rsi]) per the two stores above (0 or T[3]).
}
```

(The very last `mov eax,...` is implicit: `eax` was loaded with `T[3]` at 0x180003d0e on the
non-zero path, and `r9d`=0 path leaves eax = the qsort/`r9d` zero — the caller mostly reads the
out-pointer `*rsi_out`, so `eax` is secondary. Marked as inferred.)

## Callees

- `0x1800031c0` — guarded count-checked fill thunk: `fill(grid, 0x80, cells)` (memset-of-byte over `W*H`). See `func_1800031c0.md`. (forwards to `0x1800e0a60`.)
- `0x180003a00` — clipped box-fill rasteriser: paints a `2*delta+1` square of `fill` around keypoint[idx]'s (x,y) into `grid`. See `func_180003a00.md`. **No** transform math.
- `0x1800095c0` — generic `qsort(base, num, size, compar)` (2443 bytes, calls the comparator via `[rsp+0x98]`/`r10`). Used here as `qsort(grid, cells, 1, byte_cmp)`. See `func_1800095c0.md` (not yet written).
- `0x180003480` — qsort comparator: `int cmp(const void*a,const void*b){ return (int)*(uint8_t*)a - (int)*(uint8_t*)b; }` → **ascending unsigned-byte** sort. (3 instrs, inlined; see disasm.)

## GDB verification hooks

To verify a Python re-implementation produces identical intermediates, set breakpoints:

- `break *0x180003b99` — after this, `r15d = W*H` (grid cell count). Dump `$r12d` (W), `$r13d` (H), `$r15d`. Confirms grid sizing.
- `break *0x180003bc3` — entry to the `0x80` fill. Dump `$rcx` (=grid ptr `rbp`), `$dl`(=0x80), `$r8d`(=cells). Lets you snapshot the grid buffer before/after.
- `break *0x180003c13` — the inner box-paint call (loops `n` times). On each hit dump:
  `$rcx`=idx (A[i]), `$edx`=5 (delta), `$r8b`=fill (B[i]), `$r9b`=W, `BYTE[$rsp+0x20]`=H,
  `QWORD[$rsp+0x28]`=grid, `QWORD[$rsp+0x30]`=kp_base. Plus read `int[2]@(kp_base+idx*0x20+0x14)`
  for the (x,y) being painted. This is the core "which cell gets which level" mapping.
- `break *0x180003c47` — the qsort call. Dump `$rcx`(grid),`$edx`(=cells, num),`$r8d`(=1, size),`$r9`(=0x180003480). Dump the first/last 32 bytes of `grid` right **after** to confirm ascending sort.
- `break *0x180003c75` (`L_have_count`) — dump `$r11d`. This is `(#filled cells - 1)` (or -1). The single most important scalar: the occupancy/population count. Compare against your Python count of non-0x80 cells.
- `break *0x180003cc3` — inside the classify pass, the only **write** into the work table: dump
  `$ebx`(=j, the level being stored), `$edx`(=seed value), `$eax` (grid[j] high side),
  and `$rcx`-`(rsp+0x40)` (which of the 5 slots). Captures the binning decisions.
- `break *0x180003cf7` — the monotone-fixup zeroing: dump `$rcx-rdi` (slot i) and the table before/after; confirms the "T[i]>T[i+1] ⇒ T[i]=0" rule.
- `break *0x180003d09` and `break *0x180003d11` — the final `*out_level` store. Dump `[$rsi]` after:
  0 on the d09 path, else `T[3]` (`int@(rdi+0xc)`) on the d11 path. Also dump all 5 ints at the
  table ptr (`$rdi`) to capture the full decision table the caller may read.

Suggested one-shot table dump (at d13, epilogue): `x/5dw $rdi` (the int[5] result table) and
`x/1dw $rsi` (the scalar result).

## Confidence & open questions

**Solid:**
- Grid sizing `cells = W*H`, init-to-`0x80`, paint loop calling the box rasteriser per keypoint,
  the `qsort(grid, cells, 1, ascending-byte)`, the trailing-`0x80` scan giving `r11 = filled-1`,
  the 5-seed table `{0x11,0x21,0x31,0x41,0x51}`, the interval/classify pass, the 4-step monotone
  fixup, and the final `*out_level = (r11==0)?0:T[3]`. All addresses transcribed from the disasm.
- Comparator semantics (ascending unsigned byte) — read directly from `0x180003480`.
- This contains **no** rigid/similarity-transform / Q16 / trig / matrix math. (solid)

**Inferred / open:**
- Exact *semantic* meaning of the seed bytes `0x11..0x51`: they behave as ascending integer interval
  edges (17,33,49,65,81) against the **sorted grid byte values** `grid[j-1]/grid[j]`, while the loop
  index `j` (1..filled-1) is what gets stored. So the table maps "the gap where threshold T lands" →
  "the population index j at that gap." The `(level<<4)|1` reading is a guess; could equally be raw
  thresholds 17/33/49/65/81. Needs a captured run to disambiguate.
- The `rdi`/`rsi` out-pointers are only explicitly loaded on the **n==0** path (0x180003c22/0x180003c2a).
  On the paint path they are *not* reloaded, yet the tail writes through them. This is a compiler
  tail-merge: the two predecessors of `L_after` (0x180003c32) must both leave `rdi`=table-ptr and
  `rsi`=result-ptr. The paint loop leaves `rdi`=0 (decremented to 0) and `rsi`=B — which would be
  **wrong** unless the real entry also pre-seeds rdi/rsi, OR the caller passes the table/result as the
  same buffers reachable both ways. **This is the main open question** — confirm by breaking at
  0x180003c78 on the paint path and checking `$rdi`/`$rsi` actually point at the caller's int[5]/int.
  (Most likely the disassembly window elides that `rsi`/`rdi` are re-established; verify in gdb.)
- `arg1_rdx` and `arg2_r8d`: spilled in the prologue but not obviously reused — likely dead or used
  only via the merged-tail register state. Marked unknown.
- `eax` return value vs the out-pointer: callers almost certainly read `*out_level`; `eax` mirrors the
  last store but is treated as secondary.
- Role in the bigger picture: this is a **coverage/quality binning** metric over the keypoint splat,
  not the sec0_pre transform computation. It likely gates frame acceptance or picks a coverage
  "level," feeding the enrollment logic rather than the rigid transform itself.
