# sub_180007fe0 — register/initialize a frame slot in the geometry table (NOT transform math)

`sub_180007fe0` is a **bookkeeping / slot-initialization** routine, not a math
routine. Given a frame index `idx`, it:

1. `memset`s a per-frame byte "seen/used" flag array to 0 and marks `grid[idx]=1`,
2. copies a 16-byte record (`rbp`) into slot `idx` of a 16-byte-stride array (`r14`),
3. fills two `int[N]` correspondence/assignment arrays with `0xFFFFFFFF` (= -1 sentinel),
4. optionally writes a 20-byte record into slot `idx` of an optional output array (`r8`),
5. copies five 32-bit fields out of a source struct (`rdx`, offsets 0x68/0x88/0x98/0x9c/0xa0)
   into a small output/header struct (`rcx`, offsets 0x28/0x2c/0x3c/0x40/0x44),
6. sets `*out_ok = 1`.

There is **no** fixed-point arithmetic, no `>>16`/`*65536`/`0x8000` rounding, no
matrix/affine multiply, no atan2/sqrt/trig, and no RANSAC/voting/sort here. The
five copied fields are opaque 32-bit words (they *may* carry Q16 transform
components computed elsewhere, but this function does not compute or transform
them — it only relocates them). All "math" is index/stride address arithmetic.

Notes / caveats:
- `idx` is read as a **byte** twice (`movzx`, at 0x18000802e and 0x180008088).
- `N` is read as a **signed** 32-bit int (`movsxd`) and used both as the `memset`
  length-of-flags and to derive `4*N` byte sizes for the two int-array fills.
- args #6, #8, #13, #14 are never touched by this function (gaps in the slot map).

```c
void sub_180007fe0(int *assign_a /*rcx*/, int *assign_b /*rdx*/,
                   int *out_count /*r8*/, void *rec16_array /*r9*/, ...)
{

    // [home-slot spills]: [rsp+8]=rcx(arg0), [rsp+0x10]=rdx(arg1),
    //                     [rsp+0x18]=rbx(saved), [rsp+0x20]=rbp(saved)
    // push rsi,r12,r13,r14,r15 ; sub rsp,0x20

    int      N    = (int)*(int*)(rsp+0xc8);   // 0x180008001  movsxd r12, [rsp+0xc8]  (SIGNED count, arg#16)
    uint8_t *grid = *(uint8_t**)(rsp+0x70);   // 0x180008009  rbx = arg#5 (byte flag array)
    int     *out_count = r8 -> r15;           // 0x18000800e  r15 = arg2
    void    *rec16_array = r9 -> r14;         // 0x180008014  r14 = arg3 (16-byte stride array base)

    // ---- memset(grid, 0, N) if N>0 ----        0x180008011 .. 0x180008021
    if (N > 0) {                              // 0x180008011 test r12d,r12d ; 0x18000801a jle 0x180008026
        // rcx=grid, edx=0, r8=N
        memset(grid, 0, N);                  // 0x180008021  call 0x1800e0a60  (memset)

    void    *src_struct = *(void**)(rsp+0x98);// 0x180008026  rbp = arg#10 (src 16-byte record)  *** see note: rbp here is the SOURCE RECORD, reused below
    uint8_t  idx = *(uint8_t*)(rsp+0x90);     // 0x18000802e  movzx r13d, byte [rsp+0x90]  (frame index)
    int     *assign_a = *(int**)(rsp+0x50);   // 0x180008037  rcx = arg0 (re-loaded from home slot)

    grid[idx] = 1;                            // 0x18000803c  mov byte [r13+rbx], 1   (mark slot idx used)

    // rsi = 2*idx  -> used as [r14 + rsi*8] == [r14 + idx*16] : 16-byte record slot
    size_t rsi = (size_t)idx * 2;             // 0x180008045/0x180008048  rsi=r13; rsi+=rsi

    // ---- copy 16-byte source record (rbp) into rec16_array[idx] ----  0x180008042..0x18000806f
    *(int*)((char*)rec16_array + idx*16 + 0x0) = *(int*)((char*)src_struct + 0x0); // 0x180008042/0x180008055
    *(int*)((char*)rec16_array + idx*16 + 0x4) = *(int*)((char*)src_struct + 0x4); // 0x180008059/0x18000805f
    *(int*)((char*)rec16_array + idx*16 + 0x8) = *(int*)((char*)src_struct + 0x8); // 0x180008064/0x180008067
    *(int*)((char*)rec16_array + idx*16 + 0xc) = *(int*)((char*)src_struct + 0xc); // 0x18000806c/0x18000806f

    // ---- fill assign_a[0..N-1] = 0xFFFFFFFF (-1) ----     0x18000805c..0x180008074
    // rcx=assign_a, dl=0xff, r8d=4*N  -> memset(assign_a, 0xff, 4*N)
    memset(assign_a, 0xff, bytes4N);          // 0x180008074  call 0x1800031c0 (guarded memset)

    // ---- fill assign_b[0..N-1] = 0xFFFFFFFF (-1) ----     0x180008079..0x180008083
    int *assign_b = *(int**)(rsp+0x58);       // 0x180008079  rcx = arg1 (home slot)
    // r8d=4*N, dl=0xff
    memset(assign_b, 0xff, bytes4N);          // 0x180008083  call 0x1800031c0 (guarded memset)

    // ---- read idx again, load optional out-array & src struct ----  0x180008088..0x1800080a3
    uint8_t idx2 = *(uint8_t*)(rsp+0x90);     // 0x180008088  movzx r11d, byte [rsp+0x90]  (== idx)

    void *src2           = *(void**)(rsp+0xa0); // 0x180008099/0x18000809c  rdx = arg#11 (src struct)

    *out_count = (int)idx2;                   // 0x1800080a4  mov [r15], r11d   (write byte index as int)

    // ---- re-copy the same 16-byte record into rec16_array[idx] (again) ---- 0x1800080a7..0x1800080c1
    *(int*)((char*)rec16_array + idx*16 + 0x0) = *(int*)((char*)src_struct + 0x0); // 0x1800080a7/0x1800080aa
    *(int*)((char*)rec16_array + idx*16 + 0x4) = *(int*)((char*)src_struct + 0x4); // 0x1800080ae/0x1800080b1
    *(int*)((char*)rec16_array + idx*16 + 0x8) = *(int*)((char*)src_struct + 0x8); // 0x1800080b6/0x1800080b9
    *(int*)((char*)rec16_array + idx*16 + 0xc) = *(int*)((char*)src_struct + 0xc); // 0x1800080be/0x1800080c1

    // ---- if out_rec20_array != NULL: write a 20-byte record at slot idx ---- 0x1800080c6..0x1800080fd
    if (out_rec20_array != NULL) {            // 0x180008099 test r8,r8 (flags) ; 0x1800080c6 je 0x180008101
        // rcx = 5*idx ; record base = out_rec20_array + idx*20  (20 = 5*4)
        size_t k = (size_t)idx * 5;           // 0x1800080cb  lea rcx,[r13+r13*4]
        char  *rec = (char*)out_rec20_array + k*4;   // base + idx*20

        *(int*)(rec + 0x4) = *(int*)((char*)src_struct + 0x0); // 0x1800080c8/0x1800080d0
        *(int*)(rec + 0x8) = *(int*)((char*)src_struct + 0x4); // 0x1800080d5/0x1800080d8
        *(int*)(rec + 0xc) = *(int*)((char*)src_struct + 0x8); // 0x1800080dd/0x1800080e0
        *(int*)(rec + 0x10)= *(int*)((char*)src_struct + 0xc); // 0x1800080e5/0x1800080e8
        // two tag/flag bytes pulled from src2 (arg#11):
        rec[0x1] = *(uint8_t*)((char*)src2 + 0x68);            // 0x1800080ed/0x1800080f1
        rec[0x0] = *(uint8_t*)((char*)src2 + 0x88);            // 0x1800080f6/0x1800080fd
    }
// L_180008101:
    // ---- copy 5 fields from src2 (arg#11) into out_hdr (arg#15) ----   0x180008101..0x18000813a
    void *out_hdr = *(void**)(rsp+0xc0);      // 0x180008107  rcx = arg#15
    // (rbx/rbp restored from home slots here — saved-reg restore, not data) 0x18000810f/0x180008114
    *(int*)((char*)out_hdr + 0x2c) = *(int*)((char*)src2 + 0x88); // 0x180008101/0x180008119
    *(int*)((char*)out_hdr + 0x28) = *(int*)((char*)src2 + 0x68); // 0x18000811c/0x18000811f
    *(int*)((char*)out_hdr + 0x44) = *(int*)((char*)src2 + 0xa0); // 0x180008122/0x180008128
    *(int*)((char*)out_hdr + 0x40) = *(int*)((char*)src2 + 0x98); // 0x18000812b/0x180008131
    *(int*)((char*)out_hdr + 0x3c) = *(int*)((char*)src2 + 0x9c); // 0x180008134/0x18000813a

    // ---- set success flag ----                0x18000813d..0x180008145
    int *out_ok = *(int**)(rsp+0x80);         // 0x18000813d  rax = arg#7
    *out_ok = 1;                              // 0x180008145  mov [rax], 1

    // ---- epilogue 0x18000814b..0x180008158 ----
    return;                                   // 0x180008158  ret
}
```

### Important subtlety: `rbp` is overloaded

`rbp` is loaded from arg#10 (`[rsp+0x98]`) at 0x180008026 and is used as the **16‑byte
source record** for both copy blocks (`[rbp+0]..[rbp+0xc]`). The body's `[rsp+0x68]`
read at 0x180008114 (`mov rbp,[rsp+0x68]`) is just the **saved-rbp restore** from the
home slot in the epilogue path (paired with `mov rbx,[rsp+0x60]` at 0x18000810f) — it
is not a data load. (The pseudocode names them `src_struct` (=arg#10) and `src2`
(=arg#11) to avoid confusion; arg#10 and arg#11 are two distinct source pointers.)

Magic constants:
- `0x0` memset value (zero the flag grid).
- `0xff` memset value → 32-bit lanes become `0xFFFFFFFF` = **-1**, the standard
  "unassigned correspondence / no-match" sentinel for the two `assign_*` arrays.
- `0x1` = the "used"/success flag values (`grid[idx]=1`, `*out_ok=1`).
- Strides: **16** (`rec16_array`, via `idx*2` then `*8`) and **20** (`out_rec20_array`,
  via `5*idx` then `*4`).
- No `0x10000` / `0x8000` / shift constants — **no fixed-point here.**

## Callees

- `0x1800e0a60` — **CRT `memset`** (called directly at 0x180008021 as
  `memset(grid, 0, N)`). Confirmed elsewhere in this codebase. Not transform math.
- `0x1800031c0` — guarded `memset` thunk: `if ((int)size>0) memset(dst, byte, size)`.

## Confidence & open questions

**Solid (high confidence):**
- Control flow is fully transcribed (91 instrs): two early-out guards (`N>0` for the
  flag memset; `out_rec20_array != NULL` for the 20-byte record), straight-line otherwise.
- The two helper calls are `memset`: `memset(grid,0,N)` and two
  `memset(assign_*,0xff,4N)` (the `0xff`→-1 sentinel pattern is unambiguous).
- Strides: `rec16_array` is **16 bytes/slot** (`idx*2 *8`), `out_rec20_array` is
  **20 bytes/slot** (`5*idx *4`). `grid` is a 1-byte/slot flag array of length `N`.
- The 16-byte record is copied from arg#10 into `rec16_array[idx]` (done twice;
  identical writes — likely a compiler artifact / defensive re-store, second store
  overwrites the first with the same data).
- The 5-field header copy from arg#11 (`+0x68/+0x88/+0x98/+0x9c/+0xa0`) into arg#15
  (`+0x28/+0x2c/+0x40/+0x3c/+0x44`) is exact and order-verified.
- `*out_count = idx`, `*out_ok = 1`.
- **No fixed-point, matrix, trig, sort, or voting math is performed here.**

**Inferred / open questions:**
- Argument *names/semantics* are GUESSes. `assign_a`/`assign_b` being
  correspondence/assignment index arrays is inferred from the `int[N]` + `-1`-fill
  idiom; `grid` being a per-frame "used" flag array is inferred from `memset 0` then
  `grid[idx]=1`.
- The two source pointers arg#10 (16-byte record) and arg#11 (the struct read at
  +0x68..+0xa0) are distinct; whether they alias is unknown without a caller trace.
- The **contents** of the 16-byte record and the 5 copied header words *may* be Q16
  transform components / centroids / scores computed by a sibling function, but this
  routine neither computes nor transforms them — it only relocates them. Determining
  whether they are the `sec0_pre` rigid-transform `(a,b,tx,ty)` requires inspecting
  the caller that fills arg#10/arg#11 (recommend tracing the producer of `src2+0x68..0xa0`).
- args #6, #8, #13, #14 are unreferenced here (the caller's arg vector has gaps or
  this function ignores them).
- Whether the second 16-byte copy block is dead/defensive vs. intended (interleaved
  by the optimizer between the two memsets) — behaviorally a no-op duplicate.
