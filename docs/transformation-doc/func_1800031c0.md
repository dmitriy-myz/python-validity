# sub_1800031c0 — guarded count-checked thunk that forwards 3 args to helper `sub_1800e0a60`

This is a tiny (21-byte / 7-instruction) leaf wrapper. It sign-extends its third
argument (a 32-bit `int` count/length), and **only if that count is strictly
positive (> 0)** does it tail-style forward `(rcx, rdx, r8)` to the helper at
`0x1800e0a60`. If the count is `<= 0` it returns immediately doing nothing.

It contains **no** coordinate math, no fixed-point arithmetic, no matrix/affine
ops, and no transform-relevant logic of its own — it is pure control-flow glue.
Any transform/geometry work would live inside the callee `sub_1800e0a60`
(not provided; very high address ⇒ likely a CRT/runtime or shared inner helper
such as a fill/copy/process-over-N-elements routine).
