# sub_180007b30 — per-candidate frame-pair evaluator: reproject, score correspondences, accumulate weighted means, and commit accepted frames into the sec0_pre geometry table

This is the **driver loop** that turns a list of candidate frame-pair indices into committed
geometry. For each candidate `idx` in an input index array it:

1. Composes the candidate's stored rigid Q16 transform via `sub_180006cc0` (B∘A composition) into
   a local scratch transform (`[rsp+0xb0]`).
2. Runs a guarded per-frame serialize/load (`sub_180006470`).
3. Builds keypoint correspondences **twice** with `sub_1800041d0` (forward and reverse roles —
   the descriptor/orientation reproject-and-match worker), accumulating match counts / distance
   sums into local scratch counters (`[rsp+0x80 .. 0x98]`).
4. Computes a paired orientation-agreement score (`sub_180004060`).
5. Folds the per-candidate counts into **running weighted means** stored in the output context
   `rdi` at `+0x28/+0x2c/+0x3c/+0x40/+0x44` — each is the classic *incremental weighted average*
   `avg = (avg_old*w_old + new*w_new) / (w_old + w_new)` done in integer arithmetic with `idiv`.
6. If a global enable flag (`[rsp+0x5d8]`) is set **and** a 2-byte orientation-bucket range gate
   (`sub_18000b3d0`) passes, it copies the freshly computed 20-byte (5×int32) transform/record
   into a per-keypoint output table `rsi` (stride 0x14).
7. Runs a final acceptance check (`sub_180004190`), and on success **marks the candidate as used**
   (occupancy byte `r15`), **commits** the 16-byte transform into the master per-keypoint geometry
   array `rbp` (stride 0x20, i.e. `rbp + (2*idx)*8`), and appends `idx` to an output index list
   (`[rsp+0xe0]`, count at `[r12]`).

So this is *not* the function that computes a transform from scratch — the transform comes in
precomputed (composed by `sub_180006cc0`). This function **evaluates** each candidate transform by
reprojection/scoring and **decides which frame pairs get written into the sec0_pre-bound master
geometry table**, plus maintains the per-template aggregate quality means.

The actual fixed-point matrix math lives in the callees (`sub_180006cc0`, `sub_1800041d0`). The
math *in this body* is integer accumulation + `idiv` running means and a few range gates.

## Signature

x64 Windows ABI. 4 register args + a large block of stack args. Many entry-relative stack slots
are read straight through (offsets are exact; the prologue pushes 7 regs + `sub rsp,0x500`, so an
entry-relative arg at `[rsp_entry+0xK]` is reached as `[rsp+0x500+0x38+0xK]` post-prologue — the
disasm already shows the resolved post-prologue offsets, listed below).

```c
// All "Q16" = 16.16 signed fixed point. Names are inferred; offsets are exact.
typedef struct {                 // 4-int32 rigid similarity transform (sec0_pre record layout)
    int32_t a;   // +0x00  R[0][0] = cos*65536
    int32_t b;   // +0x04  R[1][0] = sin*65536  (R[0][1] = -b)
    int32_t tx;  // +0x08  translation x (Q16)
    int32_t ty;  // +0x0c  translation y (Q16)
} q16_xform_t;   // 16 bytes

void sub_180007b30(
    /* ecx */ int32_t        count,          // number of candidate indices to process (movsxd -> r13). If <=0, function is a no-op.
    /* rdx */ int32_t*       out_idx_count,  // -> r12 : pointer to the running "accepted index" counter (int32 at *r12), incremented on commit
    /* r8  */ const int32_t* cand_idx,       // -> rbx : base of candidate-index array (int32 each, stride 4). cand_idx[k] = idx, cand_idx-relative pair partner at (r9+rbx)
    /* r9  */ const int32_t* pair_partner,   // base such that *(int*)(r9 + rbx) = partner index for this candidate (after sub r9,rbx => r9 = (pair_partner - cand_idx) byte delta)

    /* [rsp+0x568] */ q16_xform_t* master_geom,   // -> rbp : MASTER per-keypoint geometry array (stride 0x20; record written at rbp + (2*idx)*8 = rbp + idx*0x10)
    /* [rsp+0x570] */ uint8_t*     used_flags,     // -> r15 : per-keypoint "already used / committed" byte map (indexed by idx); 0=free, 1=committed
    /* [rsp+0x578] */ void*        frameA_ctx,     // saved to [rsp+0xe0]; later used as out-index list base for appended idx  (see commit block)
    /* [rsp+0x580] */ void*        algo10,         // -> r10 : algorithm/object handle; ->[0x18] = keypoint-array-of-arrays table (per-frame kp arrays)
    /* [rsp+0x588] */ void*        frame_obj,      // saved to [rsp+0xa8]; ->[0x10] used as a frame pointer arg into the correspondence builders
    /* [rsp+0x590] */ const uint8_t* sect_ids,     // -> r14 : 2-byte section/frame id pair: [r14+0]=idA, [r14+4]=idB; [r14+0x10]=aux ptr
    /* [rsp+0x5a0] */ void*        arg_a0,         // saved to [rsp+0xd8]; arg to sub_180006470 (serialize/load dispatcher) as rdx
    /* [rsp+0x5a8] */ /* unused here */
    /* [rsp+0x5b0] */ void*        kp_record_out,  // -> rsi : per-keypoint OUTPUT record table (stride 0x14 = 1 tag byte + 16B transform), written under the range-gate block
    /* [rsp+0x5b8] */ void*        ctx_out,        // -> rdi : OUTPUT aggregate context; holds running weighted means at +0x28/+0x2c/+0x3c/+0x40/+0x44 and weights at +0x40/+0x44 base
    /* [rsp+0x5c0] */ void*        arg_d0,         // saved to [rsp+0xd0]; passed as rcx to sub_1800041d0 (and as rcx to sub_180004190)
    /* [rsp+0x5c8] */ void*        arg_a0_2,       // saved to [rsp+0xa0]; passed as r9/r8 to sub_1800041d0 and as rdx to sub_180004190
    /* [rsp+0x5d8] */ int32_t      enable_record   // gate: if non-zero, the per-keypoint output record (rsi) block runs (subject to range gate)
);
```

> NOTE on the `[rsp+0x5xx]` numbering: at entry, the first stack arg (arg5) is at `[rsp+0x28]`
> *before* the prologue. After `push rbx;push rbp;push rsi;push rdi;push r12-r15` (7×8=0x38) and
> `sub rsp,0x500`, that arg5 slot is at `[rsp+0x28+0x38+0x500] = [rsp+0x560]`. So `[rsp+0x568]` =
> arg6, `[rsp+0x570]` = arg7, etc. The mapping above uses the post-prologue offsets exactly as they
> appear in the disasm.

## Pseudocode

```c
void sub_180007b30(int count, int* out_idx_count, const int* cand_idx, const int* pair_partner, /*stack…*/)
{
    // ---- prologue / stack-arg spill ----                              // 0x180007b30..0x180007bf0
    // [rsp+0x4f0] = __security_cookie ^ rsp                             // 0x180007b47
    void* frameA_ctx   = *(void**)(rsp+0x578);  // -> [rsp+0xe0]          // 0x180007b5b / 0x180007b93
    void* algo10       = *(void**)(rsp+0x580);  // r10                    // 0x180007b63
    q16_xform_t* master_geom = *(void**)(rsp+0x568);  // rbp             // 0x180007b6b
    uint8_t* used_flags      = *(void**)(rsp+0x570);  // r15             // 0x180007b73
    const uint8_t* sect_ids  = *(void**)(rsp+0x590);  // r14             // 0x180007b7b
    void* kp_record_out      = *(void**)(rsp+0x5b0);  // rsi             // 0x180007b83
    void* ctx_out            = *(void**)(rsp+0x5b8);  // rdi             // 0x180007b8b
    void* frame_obj          = *(void**)(rsp+0x588);  // -> [rsp+0xa8]    // 0x180007b9b
    int* out_idx_count = rdx; -> r12                                      // 0x180007ba6  (mov r12,rdx)
    const int* cand_idx = r8; -> rbx                                      // 0x180007ba3  (mov rbx,r8)
    *(void**)(rsp+0xc8) = algo10;                                         // 0x180007bb9
    *(void**)(rsp+0xd8) = *(void**)(rsp+0x5a0);   // arg_a0               // 0x180007bc1
    int64 r13 = (int64)(int)count;   // SIGNED movsxd                     // 0x180007bd1
    *(void**)(rsp+0xd0) = *(void**)(rsp+0x5c0);   // arg_d0               // 0x180007bd4
    *(void**)(rsp+0xa0) = *(void**)(rsp+0x5c8);   // arg_a0_2             // 0x180007be4

    if (count <= 0) goto L_done;                       // jle            // 0x180007bec

    // r9 := pair_partner - cand_idx  (byte delta, so *(int*)(r9+rbx) = partner)  // 0x180007bf2
    *(int64*)(rsp+0xc0) = r9 = (r9 - rbx);                                // 0x180007bf5

    do {  // ---- per-candidate loop (r13 = remaining count) ----        // L_loop: 0x180007c00
        int idA = cand_idx[0];                 // r8 = *(int*)rbx (SIGNED)  // 0x180007c00 (movsxd r8,[rbx])
        if (used_flags[idA] != 0)              // cmp byte[r8+r15],0      // 0x180007c03
            goto L_next;                       // already committed -> skip // 0x180007c08 (jne 0x180007fa5)

        // ---- (1) fetch this candidate's stored transform & compose ----
        int  idB    = *(int*)(r9 + rbx);       // partner index (SIGNED)  // 0x180007c0e (movsxd rdx,[r9+rbx])
        void* kpset = *(void**)(algo10 + 0x18);                           // 0x180007c12
        void* kpA   = *(void**)(kpset + idA*8);  // per-frame kp array     // 0x180007c16
        // r8 = &kpA[idB*5*4 + 4]  ==  &kpA->kp[idB] + 0x4   (stride 0x14=5*int32)  // 0x180007c1a/0x180007c22
        //   rcx = idB*5 ; rdx = idB<<4 (=idB*16) ; r8 = kpA + rcx*4 + 4
        // rdx = master_geom_base(rbp) + idB*16   -> 'A' transform (existing record)  // 0x180007c1e/0x180007c2f
        // out = [rsp+0xb0]  (rcx)
        sub_180006cc0(/*rcx*/ out=&scratch_xf /*[rsp+0xb0]*/,             // 0x180007c32
                      /*rdx*/ A = master_geom + idB*16,
                      /*r8 */ B = &kpA[idB] + 4);
        //   -> scratch_xf[rsp+0xb0] = compose(B ∘ A) renormalized (Q16)

        // ---- (2) guarded per-frame serialize/load dispatch ----
        sub_180006470(/*rcx*/ idA = *(int*)rbx,                          // 0x180007c47/0x180007c49
                      /*rdx*/ arg_a0  = [rsp+0xd8],
                      /*r8 */ frame_obj = [rsp+0xa8]);

        // ---- zero the local score accumulators [rsp+0x80..0x98] (7 dwords) ----  // 0x180007c4e..0x180007c89
        int  sc[7]; memset(sc, 0, 28);   // [rsp+0x80],+0x84,+0x88,+0x8c,+0x90,+0x94,+0x98

        // ---- (3a) correspondence builder, FORWARD roles ----            // setup 0x180007c91..0x180007cfb
        //   This is sub_1800041d0(transform-and-sample correspondence builder).
        //   stack frame loaded with: r9=&[rsp+0xf0], r8=&[rsp+0x2f0], rdx=&[rsp+0x1f0], rcx=&[rsp+0x3f0]
        //   [rsp+0x58]=arg_d0 ; [rsp+0x50]=sect_ids[0] ; [rsp+0x48]=sect_ids[4] ; [rsp+0x40]=&scratch_xf
        //   [rsp+0x38]=sect_ids[0x10] ; [rsp+0x30]=frame_obj->[0x10] ; [rsp+0x28]=&[rsp+0xe8] ; [rsp+0x20]=&sc[0]
        sub_1800041d0(...);                                              // 0x180007d00

        // ---- (3b) correspondence builder, REVERSE roles ----            // setup 0x180007d05..0x180007d90
        //   sub_180003ea0 — per-frame byte stats over the just-built correspondence buffers.
        //   rcx=&sc[2](=&[rsp+0x88]), r9=&sc[3](&[rsp+0x8c]), r8=arg_a0_2, edx=0
        //   args: [rsp+0x50]=&[rsp+0xf0],[rsp+0x48]=&[rsp+0x2f0],[rsp+0x40]=&[rsp+0x1f0],
        //         [rsp+0x38]=sect_ids[0],[rsp+0x30]=sect_ids[4],[rsp+0x28]=sect_ids[0x10],[rsp+0x20]=frame_obj->[0x10]
        sub_180003ea0(...);                                             // 0x180007d95

        // ---- (3c) orientation-agreement scorer ----                     // setup 0x180007d9a..0x180007de6
        //   sub_180004060(pA/pB orientation buffers, count, mode…)
        //   r9=arg_a0_2 ; r8d=sc[1](=[rsp+0x84]) ; rcx=&[rsp+0x1f0] ; rdx=&[rsp+0x3f0]
        //   [rsp+0x38]=&sc[6](&[rsp+0x98]) ;[rsp+0x30]=&sc[5](&[rsp+0x94]) ;[rsp+0x28]=&sc[4](&[rsp+0x90]) ;[rsp+0x20]=&[rsp+0xf0]
        sub_180004060(...);                                             // 0x180007dee

        // ============================================================
        // (4) Fold per-candidate results into running WEIGHTED MEANS in ctx_out(rdi)
        //     Pattern: new_avg = (old_avg*old_w + sample*sample_w) / (old_w + sample_w)
        // ============================================================
        int w_old   = ctx_out->w1;            // edx = *(int*)(rdi+0x2c)   // 0x180007df3
        int w_new   = sc[1];                  // r11d = [rsp+0x84]         // 0x180007df6
        int w_tot   = w_old + w_new;          // r10d                      // 0x180007dfe
        ctx_out->w1 = w_tot;                  // *(int*)(rdi+0x2c) = r10d  // 0x180007e07
        // numerator = avg1*w_old + sc[3]*w_new
        int num1 = ctx_out->avg1 * w_old      // eax = (rdi+0x28)*edx      // 0x180007e0b (imul)
                 + sc[3] * w_new;             // ecx = [rsp+0x8c]*r11      // 0x180007e0f/0x180007e17
        ctx_out->avg1 = num1;                 // *(int*)(rdi+0x28)=eax     // 0x180007e1c
        if (w_tot != 0)                                                   // 0x180007e19/0x180007e1f
            ctx_out->avg1 = num1 / w_tot;     // cdq; idiv r10d            // 0x180007e21/0x180007e25

        // --- second running mean: ctx_out fields +0x3c (avg2) / +0x44 (w2) and +0x40 (avg3) ---
        int w2_old  = ctx_out->w2;            // r9d = *(int*)(rdi+0x44)   // 0x180007e28
        int w2_new  = sc[5];                  // r8d = [rsp+0x94]          // 0x180007e2c
        // tmp = w_tot * (rdi+0x40)   (avg3 weighted by composite weight) // 0x180007e34/0x180007e37
        int edx2    = w_tot * ctx_out->avg3;  // edx = r10d * *(rdi+0x40)
        int num2    = ctx_out->avg2 * w2_old  // eax = (rdi+0x3c)*r9d      // 0x180007e3b/0x180007e49
                    + sc[6] * w2_new;         // ecx = [rsp+0x98]*r8d      // 0x180007e41/0x180007e4d
        ctx_out->avg2 = num2;                 // *(int*)(rdi+0x3c)=eax     // 0x180007e56
        // r11d = edx2 + sc[?]*w_new  : ecx2 = [rsp+0x98]*r11d            // 0x180007e4f/0x180007e59
        int ecx_b   = sc[6] * w_new;          // ecx = [rsp+0x98]*r11      // (r11 = w_new from above) 0x180007e59
        int r11b    = edx2 + ecx_b;           // lea r11d,[rdx+rcx]        // 0x180007e5d
        int w3_tot  = w2_old + w2_new;        // ecx = [r9+r8]             // 0x180007e61
        ctx_out->avg3 = r11b;                 // *(int*)(rdi+0x40)=r11d    // 0x180007e67
        ctx_out->w2   = w3_tot;               // *(int*)(rdi+0x44)=ecx     // 0x180007e6b
        if (w3_tot != 0)                                                  // 0x180007e65/0x180007e6e
            ctx_out->avg2 = num2 / w3_tot;    // cdq; idiv ecx            // 0x180007e70/0x180007e73
        if (w_tot != 0)                                                   // 0x180007e76/0x180007e79
            ctx_out->avg3 = r11b / w_tot;     // cdq; idiv r10d           // 0x180007e7b/0x180007e82

        // ============================================================
        // (5) Optional per-keypoint OUTPUT record (range-gated)
        // ============================================================
        if (*(int*)(rsp+0x5d8) != 0) {        // enable_record            // 0x180007e85
            uint8_t b1 = sc[2]_lo;            // dl = byte[rsp+0x88]       // 0x180007e8f
            uint8_t b0 = sc[0]_lo;            // cl = byte[rsp+0x80]       // 0x180007e97
            if (sub_18000b3d0(/*cl*/ b0, /*dl*/ b1)) {  // range gate: b0>30 && b1<=49  // 0x180007e9f/0x180007ea4
                int idx = *(int*)rbx;                                     // 0x180007ea8
                // rsi record stride 0x14 (=5 dwords); base at rsi + idx*5*4
                // copy 16-byte transform from scratch_xf[rsp+0xb0] into rsi[idx]+0x4..0x10
                kp_record_out[idx].xf.a  = scratch_xf.a;                  // 0x180007eb7/0x180007eb9 (+0x4)
                kp_record_out[idx].xf.b  = scratch_xf.b;                  // 0x180007ebd/0x180007ec0 (+0x8)
                kp_record_out[idx].xf.tx = scratch_xf.tx;                 // 0x180007ec4/0x180007ec7 (+0xc)
                kp_record_out[idx].xf.ty = scratch_xf.ty;                 // 0x180007ecb/0x180007ece (+0x10)
                kp_record_out[idx].tag1  = (uint8_t)sc[2];   // byte +0x1 // 0x180007ed9/0x180007ee1
                kp_record_out[idx].tag0  = (uint8_t)sc[0];   // byte +0x0 // 0x180007eec/0x180007ef4
            }
        }
        // L_after_record: 0x180007ef7

        // ============================================================
        // (6) Final acceptance check  (sub_180004190 = occupancy-map scatter/test)
        // ============================================================
        // result written into [rsp+0xb0] (overwrites scratch_xf!) as 2 dwords (+0x0,+0x4)
        sub_180004190(/*rcx*/ arg_d0=[rsp+0xd0],                         // 0x180007f0f
                      /*rdx*/ arg_a0_2=[rsp+0xa0],
                      /*r8d*/ sc[0]=[rsp+0x80],
                      /*r9d*/ sect_ids[0],  /* + stack: sect_ids[4], [rsp+0x30]=sc[0],
                               [rsp+0x28]=&[rsp+0xf0], [rsp+0x20]=&[rsp+0xb0] */ );

        // ---- accept iff result[0]!=0 OR result[1]!=0 ----
        if (*(int*)(rsp+0xb0) == 0 && *(int*)(rsp+0xb4) == 0)            // 0x180007f3a/0x180007f44
            goto L_reloads;                   // reject -> skip commit    // 0x180007f4c (je 0x180007f95)

        // ============================================================
        // (7) COMMIT accepted candidate
        // ============================================================
        int idx = *(int*)rbx;                                            // 0x180007f4e
        used_flags[idx] = 1;                  // mark committed           // 0x180007f59 (byte[rax+r15]=1)
        int idx2 = *(int*)rbx;                // rcx = idx*2              // 0x180007f5e/0x180007f63
        // write 16-byte transform from [rsp+0xb0] into master_geom at rbp + (2*idx)*8 = rbp + idx*0x10
        master_geom[idx].a  = result.a;       // [rbp+rcx*8+0x0]          // 0x180007f61/0x180007f66
        master_geom[idx].b  = result.b;       // [rbp+rcx*8+0x4]          // 0x180007f6a/0x180007f6d
        master_geom[idx].tx = result.tx;      // [rbp+rcx*8+0x8]          // 0x180007f71/0x180007f74
        master_geom[idx].ty = result.ty;      // [rbp+rcx*8+0xc]          // 0x180007f78/0x180007f83
        // append idx to out-index list (frameA_ctx at [rsp+0xe0]), count at *out_idx_count(r12)
        void* out_list = *(void**)(rsp+0xe0);                            // 0x180007f7b
        int  n = *(int*)out_idx_count;        // *r12 (SIGNED)            // 0x180007f87
        ((int*)out_list)[n] = idx;            // [rdx+rcx*4]=*(int*)rbx   // 0x180007f8b/0x180007f8d
        (*out_idx_count)++;                   // *r12 += 1                // 0x180007f90

    L_reloads:                                                           // 0x180007f95
        algo10 = *(void**)(rsp+0xc8);   // r10                            // 0x180007f95
        r9     = *(int64*)(rsp+0xc0);   // pair-partner delta restore     // 0x180007f9d
    L_next:                                                              // 0x180007fa5
        cand_idx += 1;                  // rbx += 4                       // 0x180007fa5
    } while (--r13 != 0);               // sub r13,1 ; jne L_loop          // 0x180007fa9/0x180007fad

L_done:                                                                  // 0x180007fb3
    // ---- __security_check_cookie + epilogue ----
    sub_1800db580(*(rsp+0x4f0) ^ rsp);                                   // 0x180007fbe
    return;                                                              // 0x180007fdd
}
```

| `kpA[idB]` stride `0x14` | candidate's stored 5-int32 record; `+0x4` = its 16-byte transform passed as `B` to compose |
| `master_geom` (rbp) stride `0x20` | master per-keypoint geometry; record at `rbp + idx*0x10` (note `idx*2*8`) |
| `kp_record_out` (rsi) stride `0x14` | per-keypoint output record: `+0x0` tag0, `+0x1` tag1, `+0x4..0x13` 16-byte transform |
| `used_flags[idx]` (r15) | per-keypoint committed flag (0/1) |
| `sect_ids` (r14) | `[+0]`=idA byte, `[+4]`=idB byte, `[+0x10]`=aux ptr |

### Magic constants
| Const | Where | Meaning |
|-------|-------|---------|
| `0x1e` (30) | sub_18000b3d0 0x18000b3d0 | lower bound: gate passes only if first byte `> 30` |
| `0x31` (49) | sub_18000b3d0 0x18000b3d5 | upper bound: gate passes only if second byte `<= 49` |

## Callees

## GDB verification hooks

For a Python re-implementation, set breakpoints and dump these (Wine PID; `break *0x<addr>`):

1. **`break *0x180007c00`** (loop head) — dump `*(int*)$rbx` = `idA` (candidate index), and
   `byte[$r8+$r15]` = `used_flags[idA]`. Confirms iteration order and skip set. `$r13` = remaining count.
2. **`break *0x180007c32`** (just before compose) — dump:
   - `$rcx` = `&scratch_xf` (`[rsp+0xb0]`),
   - `$rdx` = `master_geom + idB*16` (the **A** transform: 4×int32 at `$rdx`),
   - `$r8`  = candidate's record `B` transform (4×int32 at `$r8`),
   - `$r9 + $rbx` already consumed: `idB = *(int*)( *(int64*)($rsp+0xc0) + $rbx )`.
   This is the exact composition input — compare against `sub_180006cc0` re-impl.
3. **`break *0x180007c37`** (right after compose returns) — dump 16 bytes at `[rsp+0xb0]` =
   composed Q16 transform `(a,b,tx,ty)`. **Primary transform-output checkpoint.**
4. **`break *0x180007d05`** (after FORWARD correspondence builder) — dump `sc[0..2]` =
   `[rsp+0x80],[rsp+0x84],[rsp+0x88]` (match-count / weight / tag).
5. **`break *0x180007d9a`** (after stats) — dump `sc[3]` = `[rsp+0x8c]`.
6. **`break *0x180007df3`** (after orientation scorer) — dump `sc[4..6]` =
   `[rsp+0x90],[rsp+0x94],[rsp+0x98]`. These five `break`s capture every scorer output that feeds the means.
7. **`break *0x180007e85`** (means committed) — dump `ctx_out` fields:
   `*(int*)($rdi+0x28)`=avg1, `+0x2c`=w1, `+0x3c`=avg2, `+0x40`=avg3, `+0x44`=w2.
   Verifies the incremental-weighted-mean arithmetic exactly.
8. **`break *0x180007e9f`** — args to range gate: `$cl`=`sc[0]` lo byte, `$dl`=`sc[2]` lo byte.
   `break *0x180007ea4` then `$eax` = gate result (1/0). Verifies the 30/49 thresholds.
9. **`break *0x180007eb7`** (record-write block) — `$rsi + $rcx*4` is the target record; dump
   `[rsp+0xb0]` (16-byte transform being copied) and the destination after.
10. **`break *0x180007f3a`** — acceptance test inputs: `*(int*)($rsp+0xb0)` and `*(int*)($rsp+0xb4)`
    (the `sub_180004190` result). `break *0x180007f4c` shows the accept/reject branch taken.
11. **`break *0x180007f59`** (COMMIT) — confirm `used_flags[idx]=1`; then at `0x180007f66` dump the
    16 bytes written to `master_geom + idx*0x10` (the committed Q16 transform — **this is what lands
    in the sec0_pre-bound master geometry**). At `0x180007f8d` dump `out_list[n]=idx` and
    `*(int*)$r12` (the appended accepted-index list + count). **Primary commit checkpoint.**

Recommended minimal set for byte-exact validation: **#3 (composed transform in), #11 (committed
transform out), #7 (means)** — these bracket the whole per-candidate decision.

## Confidence & open questions

**Solid (directly from disasm):**
- Control flow: single `do/while` over `count` candidates, early skip on `used_flags`, two-pronged
  reject/commit at the end. All addresses verified against the disasm.
- The commit writes a 16-byte Q16 transform into `master_geom[idx]` at stride `0x10` within `0x20`,
  marks `used_flags[idx]=1`, and appends `idx` to an index list with a counter. Solid.
- The incremental weighted-mean math at `+0x28/+0x2c/+0x3c/+0x40/+0x44` (imul/add/idiv, guarded by
  divisor!=0) is exact. Solid.
- `sub_18000b3d0` is fully decoded: `(cl > 30) && (dl <= 49)`. Solid.
- Roles of callees taken from their existing companion docs. Solid for the documented ones.

**Inferred / uncertain:**
- The **exact semantics of `sc[0..6]`** (which is "match count" vs "score" vs "weight") are inferred
  from how each is consumed; the producing functions write through pointer args so the mapping to
  slots is read off the call setups, but the *meaning* labels (avg1/avg2/avg3) are my naming.
- The split of which `sub_1800041d0` call is "forward" vs "reverse" is by argument symmetry; both
  use the same worker. The second scorer is actually `sub_180003ea0` (stats), and the third is
  `sub_180004060` (orientation) — labels corrected to match callee docs (not three identical
  correspondence calls).
- The precise distinction between the three running means (what each measures — descriptor-distance
  mean vs orientation mean vs count) is not provable from this function alone; needs the field
  consumers downstream.
- Arg names for the many `[rsp+0x5xx]` stack slots are best-effort; offsets are exact but several
  are only passed through to callees, so their *types* come from the callee docs.
- `[rsp+0x5d8]` (`enable_record`) and the `rsi` per-keypoint record table: this looks like the
  "also emit a debug/secondary per-keypoint transform table" path; its consumer is not in this file.
- The compose `B` operand `&kpA[idB]+0x4` assumes the per-keypoint record's transform starts at
  byte `+0x4` (consistent with the `kp_record_out` layout `+0x4..0x13` here). Reasonably solid but
  cross-check with `sub_180006cc0`'s expected input layout.
