# sub_180006bc0 — apply Q16 rigid/similarity 2D transform to a point

Leaf function (no callees). Takes one integer point `(x, y)` and a 4-element
Q16 transform `{a, b, tx, ty}`, applies the rotation+translation, rounds, and
writes the two transformed integer coordinates through two output pointers.

This is exactly the per-point evaluation of the `sec0_pre` rigid transform
`R=[[a,-b],[b,a]], t=(tx,ty)` in 16.16 fixed point.

## Signature

```c
// Applies a Q16 (16.16 fixed-point) rigid/similarity transform to integer point (x,y).
//   out_x = (a*x - b*y + tx + 0x8000) >> 16
//   out_y = (b*x + a*y + ty + 0x8000) >> 16
//
// rcx  out_x   : int*            -> receives transformed X (integer, de-scaled from Q16)
// rdx  out_y   : int*            -> receives transformed Y (integer, de-scaled from Q16)
// r8d  x       : int             -> input point X (integer pixel coord)
// r9d  y       : int             -> input point Y (integer pixel coord)
// [rsp+0x28] m : const int32_t*  -> transform = { a@0x0, b@0x4, tx@0x8, ty@0xC } (Q16)
//
// returns: void (eax not meaningfully set on exit)
void sub_180006bc0(int *out_x, int *out_y, int x, int y, const int32_t *m);
```

All four `m[]` fields are signed 32-bit (the `imul` products are 32-bit signed;
`sar` is an arithmetic/signed shift). `a` is typically `cos(theta)*65536`,
`b` is `sin(theta)*65536`; `tx,ty` are translations already pre-scaled to Q16.

## Pseudocode

```c
void sub_180006bc0(int *out_x /*rcx*/, int *out_y /*rdx*/,
                   int x /*r8d*/, int y /*r9d*/, const int32_t *m /*[rsp+0x28]*/)
{
    // --- prologue: spill callee-saved regs (no stack frame) --- // 0x180006bc0
    //   [rsp+0x8]=rbx  [rsp+0x10]=rbp  [rsp+0x18]=rsi  [rsp+0x20]=rdi  // 0x180006bc0..0x180006bcf

    const int32_t *m = (const int32_t*)*(void**)(rsp + 0x28);   // r11 = 5th arg     // 0x180006bd4
    int y_in = r9d;            // esi = y (4th arg)                                  // 0x180006bd9
    int x_in = r8d;            // edi = x (3rd arg)                                  // 0x180006bdc

    int a  = m[0];             // ebx  = *(int*)(m + 0x0)   (Q16 cos / scale)        // 0x180006bdf
    int b  = m[1];             // r9d  = *(int*)(m + 0x4)   (Q16 sin)                // 0x180006be2
    out_y_ptr = rdx;           // rbp  = rdx  (save out_y pointer)                   // 0x180006be6
    int ty = m[3];             // edx  = *(int*)(m + 0xC)   (Q16 translation Y)      // 0x180006be9

    int a2 = a;                // r10d = ebx  (copy of a)                            // 0x180006bed
    int b2 = b;                // eax  = r9d  (copy of b)                            // 0x180006bf0

    // --- the four signed 32-bit products (Q16 * integer) --- 
    a  *= y_in;                // imul ebx, esi   -> ebx  = a * y                    // 0x180006bf3
    b  *= x_in;                // imul r9d, edi   -> r9d  = b * x                    // 0x180006bf6
    rdi = *(void**)(rsp+0x20); //   restore rdi (was scratch holding x_in)          // 0x180006bfa
    b2 *= y_in;                // imul eax, esi   -> eax  = b * y                    // 0x180006bff
    rsi = *(void**)(rsp+0x18); //   restore rsi (was scratch holding y_in)          // 0x180006c02
    a2 *= x_in;                // imul r10d, r8d  -> r10d = a * x                    // 0x180006c07

    // --- X output: (a*x - b*y + tx + round) >> 16 ---
    a2 -= b2;                  // sub r10d, eax   -> r10d = a*x - b*y                // 0x180006c0b
    int tx = m[2];             // eax  = *(int*)(m + 0x8)  (Q16 translation X)       // 0x180006c0e
    int nx = a2 + tx + 0x8000; // lea r8d,[r10 + rax + 0x8000]  (add tx + Q16 round) // 0x180006c12

    // --- Y output numerator: a*y + (ty + b*x) ---
    int ny_t = ty + b;         // lea eax,[rdx + r9]  = ty + b*x                     // 0x180006c1a

    nx >>= 16;                 // sar r8d, 0x10   (signed >>16, de-scale to int)     // 0x180006c1e
    *out_x = nx;               // mov [rcx], r8d   -> write transformed X            // 0x180006c22

    int ny = a + ny_t + 0x8000;// lea ecx,[rbx + rax + 0x8000] = a*y + ty + b*x + round // 0x180006c25
    rbx = *(void**)(rsp+0x8);  //   restore rbx                                      // 0x180006c2c
    ny >>= 16;                 // sar ecx, 0x10   (signed >>16, de-scale to int)     // 0x180006c31
    *out_y = ny;               // mov [rbp+0x0], ecx  (rbp == original rdx == out_y) // 0x180006c34

    rbp = *(void**)(rsp+0x10); //   restore rbp                                      // 0x180006c37
    return;                    // ret                                               // 0x180006c3c
}
```

Final closed form (signed throughout, Q16 rounding `+0x8000`, signed `>>16`):

```
out_x = (m[0]*x - m[1]*y + m[2] + 0x8000) >> 16   // = (a*x - b*y + tx + 32768) >> 16
out_y = (m[1]*x + m[0]*y + m[3] + 0x8000) >> 16   // = (b*x + a*y + ty + 32768) >> 16
```

i.e. `[out_x; out_y] = round( R · [x; y] + t )` with `R = [[a,-b],[b,a]]` in Q16.

## Struct fields & constants

`m` = 5th argument (pointer at `[rsp+0x28]`), an array of four signed int32 (16 bytes):

| Access            | Reg at read     | Inferred meaning                                  |
|-------------------|-----------------|---------------------------------------------------|
| `*(int*)(m+0x0)`  | ebx (`a`)       | Q16 transform `a` (≈ cos·65536 / scale·cos)       |
| `*(int*)(m+0x4)`  | r9d (`b`)       | Q16 transform `b` (≈ sin·65536 / scale·sin)       |
| `*(int*)(m+0x8)`  | eax (`tx`)      | Q16 translation X (already ·65536)                |
| `*(int*)(m+0xC)`  | edx (`ty`)      | Q16 translation Y (already ·65536)                |
| `*(int*)rcx`      | r8d (out)       | output: transformed X (de-scaled integer)         |
| `*(int*)rbp`(=rdx)| ecx (out)       | output: transformed Y (de-scaled integer)         |

| Constant   | Meaning                                                              |
|------------|----------------------------------------------------------------------|
| `0x8000`   | 32768 = 0.5 in Q16; rounding bias added before the `>>16` truncation |
| `0x10` (16)| fixed-point fractional bits; `sar …,0x10` = signed divide by 65536   |

Notes on signedness: every multiply is `imul` (signed 32-bit, low 32 bits kept),
and both de-scales are `sar` (arithmetic shift) — so all of `a,b,tx,ty,x,y` and
the results are treated as **signed**. 32-bit overflow wraps (matches the chip).

## Confidence & open questions

Solid (high confidence):
- The closed-form transform math is unambiguous from the disassembly:
  `out_x=(a*x-b*y+tx+0x8000)>>16`, `out_y=(b*x+a*y+ty+0x8000)>>16`.
- Q16 fixed point: `0x8000` rounding + signed `sar …,16`; all products signed `imul`.
- Struct layout `{a@0,b@4,tx@8,ty@0xC}` (4 × int32) at the 5th arg.
- Output via two `int*` pointers (rcx → X, rdx → Y); function returns void.
- Leaf function, no calls.

Inferred / open:
- The semantic labels `a≈cos·65536`, `b≈sin·65536` are inferred from the
  `[[a,-b],[b,a]]` structure (a rotation/similarity), consistent with the
  sec0_pre rigid transforms. The raw code only knows them as `m[0],m[1]`.
- Whether the magnitude of `(a,b)` is a pure rotation (`a²+b²=65536²`) or a
  scaled similarity is not determined here — that depends on how the caller
  (`sub_1800041d0`) fills `m[]`. Verify with the entry hook.
- `m` could be a larger struct; only the first 16 bytes (`+0..+0xF`) are read.
