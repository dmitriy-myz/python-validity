# sub_180008160 — pairwise frame-correspondence loop that composes/averages Q16 rigid transforms

Double loop over a fixed-size array of `frame` records (`5 dwords = 20 bytes` each). For every
ordered pair `(i, j)` of frames that share a valid tile-coordinate (the same 2-byte tag), it
composes/blends the Q16 similarity transform stored on frame `i` into the transform slot of
frame `j` via `sub_180006cc0` (matrix compose + rotation re-normalization). It is the step that
propagates per-frame rigid alignments across all frames that observed the same physical tile —
exactly the "build sec0_pre inter-frame transform graph" stage.

## Signature

```c
// rcx = collection of frames (the geometry/template builder context)
// rdx = collection of tiles/observations (parallel "valid pair" container)
void sub_180008160(FrameArray *frames, ObsArray *obs);
```

Inferred argument layout (see struct table below):

| Arg | Reg | Type (inferred) | Meaning |
|-----|-----|------|---------|
| 1 | rcx | `FrameArray*` (`r13`, also `[rsp+0x50]`) | Array of frame records. `frame[k]` = base + `k*0x14` bytes (`k*5` dwords). Each record: `[+0x00]` = 2-byte tile tag + flags, `[+0x04 .. +0x13]` = 16-byte Q16 transform `{a,b,tx,ty}`. **(guess on exact field split — see below)** |
| 2 | rdx | `ObsArray*` (`rdi`) | `[+0x10]` = u8 count `N`; `[+0x08]` = ptr to `N` tile-tag bytes; `[+0x18]` = ptr to array of pointers, `[+0x18][i]` → buffer of per-frame transform records. |

Return: `void` (eax not set on exit; the work is the in-place writes done by `sub_180006cc0`).

Note: the function mirrors the outer index `i` (`r12d`) against the *same* count
`obs->count` at `[rdx+0x10]`, so `frames` and `obs` are parallel arrays of the same length `N`.

## Pseudocode

```c
void sub_180008160(FrameArray *frames /*rcx*/, ObsArray *obs /*rdx*/)
{
    // 0x180008160  spill rcx -> [rsp+0x8]; prologue saves rdi,r12,r13; sub rsp,0x30
    int32_t i  = 0;                      // r12d   0x18000816e  xor r12d,r12d
    ObsArray *o = obs;                   // rdi    0x180008171
    FrameArray *F = frames;              // r13    0x180008174  (== [rsp+0x50] after spill)

    uint8_t N = obs->count;              // 0x180008177  cmp BYTE[rdx+0x10], r12b(0)
    if (N == 0) goto epilogue;           // 0x18000817b  jbe 0x180008288  (N<=0 -> done)

    // 0x180008181..0x180008195  save rbx,rbp,rsi,r14,r15 into shadow slots
    int64_t i_tagoff = 0;                // r14    0x18000819a  xor r14d,r14d  (== i*4 bytes)

    // ---- OUTER LOOP over i = 0..N-1 ----
L_outer: // 0x1800081a0
    int64_t ii = (int64_t)(int32_t)i;            // 0x1800081a0  movsxd rax,r12d
    int64_t i5 = ii + ii*4;                      // r15   0x1800081a3  lea r15,[rax+rax*4]  (== i*5 dwords)
    void *p_i = (char*)F + i5*4;                 // rcx   0x1800081a7  lea rcx,[r13 + r15*4 + 0]  (== &F[i])
    int valid_i = call sub_18000b3f0(p_i);       // 0x1800081ac  arg = &frame[i].tag (reads byte[+0],[+1])
    if (valid_i == 0) goto L_next_i;             // 0x1800081b3  je 0x18000825a  (tile tag out of [31..49] band)

    int32_t  j   = 0;                            // ebx   0x1800081b9  xor ebx,ebx
    uint8_t  Nj  = obs->count;                   // 0x1800081bb  cmp BYTE[rdi+0x10], bl(0)
    if (Nj == 0) goto L_next_i;                  // 0x1800081be  jbe 0x18000825a

    int64_t  j_byteoff = 0;                      // rsi   0x1800081c4  xor esi,esi   (== j*8, index into ptr array)
    int64_t  j_tagoff  = 0;                      // rbp   0x1800081c6  xor ebp,ebp   (== j*4? — see note; used as byte index)

    // ---- INNER LOOP over j = 0..Nj-1 ----
L_inner: // 0x1800081d0
    void  *ptab   = obs->ptrs;                   // rax   0x1800081d0  mov rax,[rdi+0x18]
    void  *rowj   = *(void**)((char*)ptab + j_byteoff); // rcx 0x1800081d4  mov rcx,[rax + j*8]
    void  *xform_j = (char*)rowj + i5*4 + 4;     // rcx   0x1800081d8  lea rcx,[rcx + i*5dw*4 + 4]  -> &row[j].xform[i]
    int   set_j = call sub_18000b420(xform_j);   // 0x1800081dd  nonzero if xform != Q16 identity
    if (set_j == 0) goto L_next_j;               // 0x1800081e4  je 0x180008243

    uint8_t *tags = obs->tags;                   // rcx   0x1800081e6  mov rcx,[rdi+0x8]
    uint8_t  tag_i = tags[i_tagoff];             // al    0x1800081ea  movzx eax,BYTE[r14 + rcx]  (== tags[i])
    uint8_t  tag_j = tags[j_tagoff];             //       0x1800081ef  cmp BYTE[rcx + rbp], al   (== tags[j])
    if (tag_j != tag_i) goto L_next_j;           // 0x1800081f2  jne 0x180008243  (only pair frames with same tile tag)

    // p_j = &frame[j]   (note: F is reloaded from spill each iteration below)
    int64_t jj = (int64_t)(int32_t)j;            // 0x1800081f4  movsxd rax,ebx
    int64_t j5 = jj + jj*4;                       // rcx   0x1800081f7  lea rcx,[rax+rax*4]  (== j*5 dwords)
    void *xform_jframe = (char*)F + j5*4 + 4;     // r13   0x1800081fb  lea r13,[r13 + j5*4 + 4]  -> &F[j].xform
    int set_jf = call sub_18000b420(xform_jframe);// 0x180008200..0x180008203  rcx=r13
    if (set_jf != 0) goto L_restore_skip;        // 0x18000820a  jne 0x18000823e  (F[j] already has a transform -> skip)

    if (i == j) goto L_restore_eq;               // 0x18000820c..0x18000820f  cmp r12d,ebx; je 0x180008237

    // ----- the actual transform compose/blend (only when i!=j and F[j] empty) -----
    void *ptab2   = obs->ptrs;                    // rax  0x180008211  mov rax,[rdi+0x18]
    void *rowj2   = *(void**)((char*)ptab2 + j_byteoff); // rdx 0x180008218  mov rdx,[rax + j*8]
    FrameArray *Fbase = *(FrameArray**)(rsp+0x50);// rax  0x18000821c  reload F base
    void *src_xform = (char*)rowj2 + i5*4 + 4;    // r8   0x180008221  lea r8,[rdx + i5*4 + 4]  (== &row[j].xform[i])
    void *dst_xform = (char*)Fbase + i5*4 + 4;    // rdx  0x180008226  lea rdx,[Fbase + i5*4 + 4] (== &F[i].xform)
    // rcx still = r13 = &F[j].xform  (the OUTPUT)
    sub_180006cc0(/*rcx*/ &F[j].xform, /*rdx*/ &F[i].xform, /*r8*/ &row[j].xform[i]); // 0x18000822b
    F = *(FrameArray**)(rsp+0x50);                // r13  0x180008230  restore F base ptr

    goto L_next_j;                                // 0x180008235  jmp 0x180008243

L_restore_eq:   // 0x180008237
    F = *(FrameArray**)(rsp+0x50);                // r13  0x180008237  restore F base; fallthrough
    goto L_next_j;                                // 0x18000823c  jmp 0x180008243

L_restore_skip: // 0x18000823e
    F = *(FrameArray**)(rsp+0x50);                // r13  0x18000823e  restore F base; fallthrough

L_next_j: // 0x180008243
    Nj  = obs->count;                             // al   0x180008243  movzx eax,BYTE[rdi+0x10]
    j  += 1;                                       // 0x180008247  add ebx,1
    j_tagoff  += 4;                                // rbp  0x18000824a  add rbp,4
    j_byteoff += 8;                                // rsi  0x18000824e  add rsi,8
    if (j < (int)Nj) goto L_inner;                // 0x180008252  cmp ebx,eax; jl 0x1800081d0

L_next_i: // 0x18000825a
    N    = obs->count;                            // al   0x18000825a  movzx eax,BYTE[rdi+0x10]
    i   += 1;                                      // r12d 0x18000825e  add r12d,1
    i_tagoff += 4;                                 // r14  0x180008262  add r14,4
    if (i < (int)N) goto L_outer;                 // 0x180008266  cmp r12d,eax; jl 0x1800081a0

    // 0x18000826f..0x180008283  restore r15,r14,rsi,rbp,rbx from shadow slots
epilogue: // 0x180008288
    // add rsp,0x30; pop r13,r12,rdi; ret
    return;                                        // 0x180008291
}
```

### Important subtlety: the inner `j_tagoff` stride
`rbp` advances by **4** per inner iteration (`0x18000824a`) and is used as `tags[rbp]`
(`0x1800081ef`). The outer `r14` advances by **4** per outer iter and indexes `tags[r14]`
(`0x1800081ea`). If `tags[]` were a flat byte array indexed by frame number, the stride would be
1, not 4. The stride-4 means **the tag-pointer at `obs->tags` (`[rdx+0x8]`) actually points at the
first byte of the same `0x14`-stride frame records** (so `4` here is part-stride, not full
`0x14`) — OR `tags` is an array of 4-byte structures whose first byte is the tile tag. Treat the
exact stride as **a verification target** (see hooks); the *intent* is clear: compare `tag_i`
vs `tag_j` and only fuse frames that saw the same tile.

## Struct fields & constants

### Frame record `F[k]` (rcx / r13, stride `0x14` = 5 dwords)
| Access | Meaning (inferred) |
|--------|--------------------|
| `&F[k]` = `F + (k*5)*4` | base of frame record k. `k*5` computed as `lea r15,[rax+rax*4]` then `*4`. |
| `F[k] + 0x00` (bytes [0],[1]) | 2-byte **tile coordinate / tag**; read by `sub_18000b3f0` for the validity gate. |
| `F[k] + 0x04 .. +0x13` | **16-byte Q16 transform** `{a, b, tx, ty}` (4 dwords). Tested for identity by `sub_18000b420`, written by `sub_180006cc0`. |

### Observation container `obs` (rdx / rdi)
| Access | Meaning |
|--------|---------|
| `[rdx+0x08]` | `tags` — pointer used as `tags[i*4]`, `tags[j*4]` (tile-tag bytes; stride 4 — see subtlety). |
| `[rdx+0x10]` | `count` (u8) `N`, the loop bound for **both** loops (parallel to frame array). |
| `[rdx+0x18]` | `ptrs` — pointer to an array of pointers; `ptrs[j]` (8-byte stride, `rsi`) → a per-frame row of transforms. `row[j] + i*5dw*4 + 4` = the `{i→j}` measured Q16 transform. |

### Magic constants
| Const | Where | Meaning |
|-------|-------|---------|
| `0x14` (k*5 dwords) | `lea [rax+rax*4]` then `<<2` | frame-record stride = 20 bytes (1 dword tag/flags + 4 dwords transform). |
| `+0x4` | `0x1800081d8`, `0x1800081fb`, `0x180008221`, `0x180008226` | skip the leading dword (tag) to reach the 16-byte transform. |
| `*8` (rsi) | `0x18000824e` | pointer-array stride in `obs->ptrs`. |
| In `sub_18000b3f0`/`b3d0`: `0x1e`(30), `0x31`(49) | tag-band gate | valid tile-tag requires `byte0 > 30` AND `byte1 <= 49`. |
| In `sub_18000b420`: `0x10000, 0,0,0` | Q16 identity | transform "is set" iff it differs from `{a=1.0(Q16), b=0, tx=0, ty=0}`. |

## Callees

- `0x18000b3f0` — tag-validity gate. Loads `byte[rcx]`→cl, `byte[rcx+1]`→dl, tail-calls `0x18000b3d0` which returns `1` iff `cl > 0x1e (30)` **and** `dl <= 0x31 (49)`, else `0`. (i.e. "is this frame's tile coordinate inside the usable band?")
- `0x18000b420` — Q16-identity test. Returns `0` iff the 16-byte transform == `{0x10000, 0, 0, 0}` (identity), else `1` ("transform is set"). No callees.
- `0x180006cc0` — **Q16 similarity-transform compose** (the math core). `rcx`=out, `rdx`=A `{a,b,tx,ty}`, `r8`=B `{a,b,tx,ty}`. Computes:
  - `out.a  = ( (A.a>>1)*(B.a>>1) - (A.b>>1)*(B.b>>1) + 0x2000 ) >> 0xE`   (`0x180006cc0..d01`) — rotation-product `cos·cos - sin·sin`, Q16·Q16→Q16 with `+0x2000` round and `>>14` (because both halved: `(>>1)·(>>1)=>>2`, product is Q32→`>>14` gives Q18, net Q16... — exact scaling is a verify target).
  - `out.b  = ( (A.a>>1)*(B.b>>1) + (A.b>>1)*(B.a>>1) + 0x2000 ) >> 0xE`   (`0x180006d04..d28`) — `sin·cos + cos·sin`.
  - `out.tx = ( (B.tx>>8)*(A.a>>2) - (B.ty>>8)*(A.b>>2) ) >> 6 + A.tx`     (`0x180006d2b..d52`) — rotate B's translation by A and add A.tx.
  - `out.ty = ( (B.tx>>8)*(A.b>>2) + (B.ty>>8)*(A.a>>2) ) >> 6 + A.ty`     (`0x180006d55..d89`) — rotate + add A.ty.
  - tail-calls `0x180006c40` to **re-normalize** the rotation vector `(out.a,out.b)` to unit length.
- `0x180006c40` — (transitive) rotation re-normalizer: `mag = sqrt((a>>1)^2 + (b>>1)^2)` via `0x180003060` (integer sqrt), then `a = (a<<14)/(mag>>1)`, `b = (b<<14)/(mag>>1)` so `(a,b)` becomes a unit Q16 cos/sin. Falls back to raw `a>>1, b>>1` if `mag>>1 == 0`. See `func_180006c40.md` / `func_180003060.md`.

## GDB verification hooks

Set these and run an enrollment that fuses ≥2 frames. All addresses are absolute (image base 0x180000000; rebase by your load slide).

1. **`break *0x1800081a7`** (entry of outer body, `&F[i]` in rcx, `i`=`r12d`, `i*5`=`r15`)
   - Dump: `p/d $r12d` (= i), `x/2bx $rcx` (frame i's tile tag bytes), `x/4wx $rcx+4` (frame i transform `{a,b,tx,ty}` Q16).
2. **`break *0x1800081ac`** → step over → check `eax` (`sub_18000b3f0` result): `p/d $eax` — 1 means tile-tag in band [31..49].
3. **`break *0x1800081ea`** (tag compare): `p/x $rdi+0x8` then `x/1bx <tags>+$r14` (= tag_i) and `x/1bx <tags>+$rbp` (= tag_j). Confirms the **stride-4** indexing and the same-tile pairing rule (open question above).
4. **`break *0x1800081d4`** (resolves `row[j]`): `p/x $rcx` then `x/4wx $rcx + $r15*4 + 4` = the measured `{i→j}` transform that becomes input B.
5. **`break *0x18000822b`** (THE compose call — most important): capture all three transforms BEFORE the call:
   - out  = `x/4wx $rcx`        (`&F[j].xform`, will be overwritten)
   - A    = `x/4wx $rdx`        (`&F[i].xform`)
   - B    = `x/4wx $r8`         (`&row[j].xform[i]`, the measured pairwise transform)
   Then **`break *0x180008230`** (just after) and re-dump `x/4wx <saved &F[j].xform>` to capture the composed result. These four 4-dword Q16 vectors are the exact I/O to byte-match a Python port of `sub_180006cc0`.
6. Inside the math, to verify fixed-point: **`break *0x180006d01`** (after `out.a` computed → `r10d`), **`*0x180006d28`** (`out.b` in eax), **`*0x180006d52`** (`out.tx` in edx), **`*0x180006d89`** (`out.ty` in r8d). `p/d` each; these are the post-round, pre-normalize Q16 components.
7. **`break *0x180006c97` / `*0x180006c95`** in the normalizer to see whether the unit-normalize path or the degenerate (`mag==0`) fallback path was taken, plus `p/d $r11d` (= mag>>1).

## Confidence & open questions

**Solid:**
- Control flow / loop structure (double loop over `N = obs[+0x10]`, inner skip on identity, same-tag gate) — transcribed directly.
- Callee roles: `b3f0`/`b3d0` = tag band gate (30<x, y≤49); `b420` = Q16-identity test (vs `{0x10000,0,0,0}`); `6cc0` = Q16 similarity compose; `6c40`/`3060` = rotation re-normalize via integer sqrt. These are read straight from their bodies.
- Frame stride = `0x14` (1 tag dword + 4 transform dwords); transform is the 16 bytes at `+0x4`.
- The compose call only fires when `i != j` AND `F[j]` is still identity AND `F[i]` is set AND tags match — i.e. it *seeds/propagates* a frame's transform to a not-yet-aligned same-tile frame.

**Inferred / to verify:**
- Exact semantics of `obs->tags` stride 4 vs frame stride 0x14 (hook #3). The two indices `r14` (outer, +4) and `rbp` (inner, +4) clearly index a per-frame tag, but whether the base `[rdx+0x8]` is a packed `u8` band or aliases the frame array needs a live dump.
- The precise Q16 scaling of `sub_180006cc0` (`>>14` after two `>>1` halvings for the rotation product; `>>6` after `>>8`/`>>2` for translation). The shift bookkeeping is consistent with "keep Q16, halve operands to avoid 32-bit overflow," but confirm with hook #6 against a known input pair.
- Whether `frames`(rcx) and `obs`(rdx) are truly parallel arrays of length `N` (the code reuses `obs->count` as the bound for both, strongly implying yes).
- `out`(rcx) of `6cc0` being `&F[j].xform` means the **result is written to the *j* frame**, while inputs are `F[i]` (A) ∘ `row[j][i]` (B). This "write composed transform into the previously-empty frame j" is the propagation step; double-check the A/B order matters for your port (compose is not commutative).
