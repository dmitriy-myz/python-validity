# sub_180004060 — paired orientation-difference accumulator (angle-distance score over a vector of byte-orientations)

This function walks a vector of `count` byte-valued orientations and, for each element, calls the
inner kernel `sub_180004010` (which folds an orientation **difference** into `[0,45]`, accumulates
it, and turns it into a 100-based weighted score). It then divides the two running accumulators by
`count` (resp. `10*count`) to produce two averaged outputs, or writes the sentinel `0x7fff` when
`count <= 0` / the per-output counter stayed `0`.

There are **two modes** selected by `r9` (`mode_flag`, arg5):
* `mode_flag == 0` → compare element `i` of buffer-A against element `i` of buffer-B directly
  (parallel scan of two arrays `pA`, `pB`).
* `mode_flag != 0` → indirect/gated mode: an index table `pIdx` maps each element through a
  per-element gate byte; only elements whose gate byte is `0` are scored, and the "other" byte is
  fetched at `pB[i]` relative to the same base.

This is **not** a rigid-transform / matrix routine. It is the **orientation-agreement scorer** used
when comparing two frames' quantized ridge-orientation streams (the byte orientation maps that feed
the geometry stage). It produces (a) a mean folded angular distance and (b) a mean 100-scaled score.

## Signature

```c
// x64 Windows ABI. NOTE: many args arrive on the stack (5+).
// rcx = r11(base) , rdx = rdi(pA) , r8d = count , r9 = mode_flag
void sub_180004060(
    const uint8_t *base,        // rcx  -> r11 : base pointer A (orientation buffer / base for offsets)
    const uint8_t *pA,          // rdx  -> rdi : second pointer; in mode0 = "other" array, used as (base - pA) delta too
    int            count,       // r8d  -> r14 : number of elements (signed; movsxd r8d)
    uint64_t       mode_flag,   // r9   -> r13 : 0 = direct parallel scan, !=0 = gated/indexed scan

    int           *pAvgAngle,   // [rsp+0x78] -> rsi : OUT — gets mean folded-angle (init 0); also = "score sum" reused
    int           *pCount,      // [rsp+0x88] -> rbp : OUT/accumulator — element count used (init 0), then = mean angle
    const uint8_t *pIdx,        // [rsp+0x70] -> r12 : index/gate table (mode!=0 only): pIdx[base_off] -> gate ptr
    const uint8_t *pGateBase    // [rsp+0x70]+? : see note — r12 indexes a table of pointers, gate at [ptr + r13]

```

> **Caller note.** The caller is `sub_1800043d0` (see callgraph). The exact OUT-vs-IN role of
> `pSumAngle`/`pAvgAngle`/`pCount` is inferred from the init-to-0 stores at entry and the divide-by-count
> at exit. Naming is best-effort. What is *certain*: there are **three** distinct `int*` accumulators
> (one passed in rcx-position to the kernel as the angle-sum, one as the score-sum, one as the counter)
> and two of them are post-divided and clamped.

The three kernel accumulators map to:
* `pCount`  ([rbp], from `[rsp+0x88]`) — the **folded-angle sum** target (`*rcx` inside kernel), divided by `count` at exit → becomes **mean angle**.
* `pAvgAngle`([rsi], from `[rsp+0x78]`) — the **score sum** target (`*r10` inside kernel), divided by `10*count` at exit → becomes **mean score**.
* `pSumAngle`([r8],  from `[rsp+0x80]`) — the **counter** (`*r8` inside kernel, `+1` per scored element); used as the `<=0` test guard for the score divide.

(The variable names above are placeholders; treat by *role*: ANGLE_SUM target, SCORE_SUM target, COUNTER.)

{

    // push rsi; push r14; sub rsp,0x38                               // 0x180004060..0x180004064

    int  *COUNTER   /*r8*/  = (int*)*(void**)(rsp+0x80);   // [rsp+0x80] // 0x180004087
    int64_t n  /*r14*/ = (int64_t)(int32_t)count;          // movsxd r8d  // 0x180004084  (SIGNED)

    *ANGLE_SUM = 0;                                                   // 0x180004094
    *SCORE_SUM = 0;                                                   // 0x18000409c
    *COUNTER   = 0;                                                   // 0x18000409e

    uint64_t mode  /*r13*/ = mode_flag;                              // 0x1800040a1
    uint8_t *pA    /*rdi*/ = rdi_pA;                                 // 0x1800040a4
    uint8_t *r11   /*r11*/ = r11_base;                              // 0x1800040a7

    if (mode != 0) goto L_MODE_INDEXED;                              // 0x1800040ad  (jne 0x1800040e4)

    // =========================================================
    // MODE 0 : direct parallel scan  (pA[i] vs base+pA delta)
    // =========================================================
    if ((int)n <= 0) goto L_FINISH_ANGLE;                            // 0x1800040af/0x1800040b2 (test r14d; jle 0x180004133)
    r11 = r11 - pA;        // r11 becomes (base - pA) byte delta       // 0x1800040b4  (sub r11,rdx)
    // 16-byte nop padding 0x1800040b7..0x1800040bd

    do {                                                             // L_LOOP0: 0x1800040c0
        uint8_t a   = *(uint8_t*)(r11 + pA);   // == base[i]          // 0x1800040c0  (movzx eax,[r11+rdi])
        uint8_t d9  = *(uint8_t*)(pA);          // == pA[i]           // 0x1800040c5  (movzx r9d,[rdi])
        // kernel args: rcx=ANGLE_SUM(rbp), rdx=SCORE_SUM(rsi),
        //              r8=COUNTER, r9=d9, [rsp+0x28]=a (weight byte)

        *(uint8_t*)(rsp+0x20) = a;   // 5th arg (read as [rsp+0x28] inside callee) // 0x1800040cf
        sub_180004010(ANGLE_SUM, SCORE_SUM, COUNTER, /*r9=*/d9, /*[rsp+0x28]=*/a); // 0x1800040d3 (call 0x180004010)
        pA += 1;                                                     // 0x1800040d8
        i  -= 1;                                                     // 0x1800040dc

    goto L_FINISH_ANGLE;                                             // 0x1800040e2  (jmp 0x180004133)

    // =========================================================

    if ((int)n <= 0) goto L_FINISH_ANGLE;                            // 0x1800040e7 (jle 0x180004133)

    uint8_t *pIdx /*r12*/ = *(void**)(rsp+0x70);                     // 0x1800040ee  (mov r12,[rsp+0x70])
    pIdx = pIdx - r11_base;   // pIdx becomes table base - r11        // 0x1800040f3  (sub r12,rcx)
    pA   = pA   - r11_base;   // pA delta vs base                     // 0x1800040f6  (sub rdi,rcx)
    // nop padding 0x1800040f9..0x180004100

    do {                                                            // L_LOOP1: 0x180004100
        // r11 currently walks from base (rcx) upward; r11 starts == r11_base
        uint8_t  idx = *(uint8_t*)(pIdx + r11);  // table[ (r11 - base)? ] // 0x180004100 (movzx eax,[r12+r11])
        // gate test: byte at (idx_as_ptr + mode) must be 0 to score
        if (*(uint8_t*)((uint64_t)idx + mode) != 0) goto L_NEXT1;    // 0x180004105/0x18000410a (cmp [rax+r13],0; jne)
            uint8_t a  = *(uint8_t*)(r11);             // base[i]      // 0x18000410c (movzx eax,[r11])
            uint8_t d9 = *(uint8_t*)(pA + r11);        // pA[i]        // 0x180004110 (movzx r9d,[rdi+r11])
            rdx = SCORE_SUM;                                          // 0x180004115
            rcx = ANGLE_SUM;                                         // 0x180004118
            *(uint8_t*)(rsp+0x20) = a;                                // 0x18000411b

    L_NEXT1:                                                         // 0x180004124
        r11 += 1;                                                    // 0x180004124 (add r11,1)
        i   -= 1;                                                    // 0x180004128
    } while (i != 0);                                               // 0x18000412c (jne L_LOOP1)
    r12 = *(void**)(rsp+0x68);   // restore r12                       // 0x18000412e

    // =========================================================
    // FINISH: average the angle accumulator
    // =========================================================

    // restore r13, rdi, rbx (spilled callee-saves)                  // 0x180004136..0x180004140
    if ((int)n <= 0) goto L_ANGLE_SENTINEL;                          // 0x180004133/0x180004145 (test r14d; jle 0x180004153)
        int s = *ANGLE_SUM;                                          // 0x180004147
        // signed divide by count
        *ANGLE_SUM = s / (int)n;        // cdq; idiv r14d             // 0x18000414a..0x18000414e
        goto L_AFTER_ANGLE;                                          // 0x180004151 (jmp 0x18000415a)
L_ANGLE_SENTINEL:                                                   // 0x180004153
        *ANGLE_SUM = 0x7fff;            // sentinel "no data" = 32767 // 0x180004153

L_AFTER_ANGLE:                                                     // 0x18000415a
    // restore rbp                                                   // 0x18000415e
    if (*COUNTER <= 0) goto L_SCORE_SENTINEL;                        // 0x18000415a/0x180004163 (cmp [r8],0; jle 0x18000417a)

        return;                                                      // 0x180004179 (ret)

        *SCORE_SUM = 0x7fff;           // sentinel = 32767            // 0x18000417a
        return;                                                      // 0x180004187 (ret)

### Inner kernel `sub_180004010(int *angSum /*rcx*/, int *scoreSum /*rdx→r10*/, int *cnt /*r8*/, uint8_t d /*r9b*/, uint8_t w /*[rsp+0x28]*/)`

```c
// 0x180004010
uint8_t d = (uint8_t)r9;                                            // 0x180004010 movzx eax,r9b
int     t = 0x5a - d;          // 90 - d                            // 0x18000401d sub r9d,eax  (0x5a = 90)
if (d < t) t = d;              // t = min(d, 90-d)  -> fold into [0,45]// 0x180004020/0x180004023 (cmovl)
*angSum += t;                  // accumulate folded angle distance    // 0x18000402c add [rcx],r9d
// score = round( (t*100) / 90 ) + 100        (magic-mul divide by 90)
int v   = t * 100;                                                  // 0x18000402f imul r9d,r9d,0x64
int hi  = (int)(((int64_t)0xb60b60b7_s * v) >> 32) + v;            // 0x180004033/0x180004036
hi      = hi >> 5;             // sar 5                              // 0x180004039
int rnd = (uint32_t)hi >> 31;  // add the sign bit (round-toward-0 fix)// 0x18000403e
int score = (hi + rnd + 100) * w;  // lea +0x64 ; imul by w          // 0x180004041/0x18000404a
*scoreSum += score;                                                 // 0x18000404d add [r10],ecx
*cnt += 1;                                                          // 0x180004050 add [r8],1
```

So per scored element: `angSum += min(d,90-d)` and `scoreSum += (round(min(d,90-d)*100/90)+100)*w`,
where `d` = one byte orientation value, `w` = the *other* byte (used as a weight/confidence).

## Confidence & open questions

**Solid (directly from disasm):**
- Two scan modes selected by `r9` (mode_flag); the loop bodies, the per-element kernel call, the
  three accumulators, the divide-by-`count` (angle) and divide-by-`10*count` (score), and the
  `0x7fff` sentinels are all exact.
- The inner kernel math is fully decoded and numerically verified: `t=min(d,90-d)`, magic-mul
  divide-by-90, `+100` base, `*w` weight, the `0x5a/0x64/0xb60b60b7` constants.
- Signedness: `count` is sign-extended (`movsxd`), both final divides are signed (`cdq; idiv`).

**Inferred / open:**
- The *semantic* names of the three OUT pointers (ANGLE_SUM/SCORE_SUM/COUNTER) and which the caller
  treats as the primary result. The "mean folded angle" and "mean 100-scaled score" interpretation
  is solid mechanically; the higher-level meaning (e.g. "orientation-agreement metric between two
  frame orientation maps") is inferred from caller context (`sub_1800043d0`).
- Mode-!=0 indexing: `[r12+r11]` yields a byte that is then used as a 64-bit *address base* in
  `[rax+r13]`. This strongly implies `idx` is actually being treated as (the low byte of) a pointer
  or that the table holds small offsets into a gate array based at 0 — i.e. the disasm reads the
  *zero-extended byte* as a pointer + `r13`(mode_flag) offset. Worth confirming live (hook #3): it
  may be that `r12`/`r13` were set up by the caller so that `idx` is a real index and the addressing
  is `gate_base[idx]` with `r13` carrying `gate_base`. The byte-`movzx` is unusual for a pointer, so
  the live dump should clarify whether `r9`(mode_flag) doubles as a gate-table base pointer.
- This routine does **not** perform any rigid/affine/Q16 transform math; it is an orientation-stream
  comparison scorer feeding the geometry/scoring stage, not the transform-fit itself.
