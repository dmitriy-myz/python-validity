# sub_180005930 — deserialize a per-frame keypoint/geometry record from a byte stream

This is a **deserializer / loader**, not transform math. It reads a fixed-layout
binary record out of a stream object (the WS / `sec0_pre`-style serialized blob)
and populates an in-memory geometry struct: a count, then a variable-length array
of per-keypoint entries, then several fixed-size "tile membership / quadrant" tables
that it fills with *computed index labels* (`tile_id*15`, `0xA5`, etc.). No fixed-point,
no trig, no matrix ops — purely structure + a couple of small `i*0xF` index formulas.

It is the read-side counterpart of the v30/sec0_pre writer (`serialize_v30_section` /
`sub_1800051f0` family). It is called by `sub_180006320`.

## Signature

```c
// rcx = stream reader object (cursor-based byte source)
// rdx = destination geometry/record struct
void sub_180005930(StreamReader *stream /*rcx -> r12*/,
                   GeomRecord  *rec     /*rdx -> rsi*/);
```

Inferred types:

```c
typedef struct StreamReader {
    /* +0x00 */ ...;
    /* +0x08 */ uint8_t *base;     // base pointer of the serialized buffer
    /* +0x10 */ uint32_t cursor;   // current read offset (advanced by reader helpers)
} StreamReader;

// The element pointed to by rec->vec (rec+0x10 -> [ptr]) is an array of 0x20-byte entries.
typedef struct KpEntry {        // stride 0x20 (shl 5)
    /* +0x00 */ void    *blob;  // sub-buffer pointer used as memcpy src at L_loop1 (read 0x10 bytes)
    /* +0x08 */ ...;
    /* +0x0C */ ...;
    /* +0x14 */ uint32_t f14;   // byte read in loop1; ALSO overwritten by the tile-label loops as (tile_id*15 / 0xA5)
    /* +0x18 */ uint32_t f18;   // byte read in loop1
    /* ...    */
} KpEntry;                       // NOTE +0x14 is reached in label loops as (idx*0x20 + 0x20) - 0x14 == idx*0x20 + 0xC

typedef struct GeomRecord {
    /* +0x0C */ uint8_t  hdrC;    // single byte read at L_readC (rec+0xC)
    /* +0x0D */ uint8_t  hdrD[?]; // 0xC..0x1F region, used as the "count12" array base [r8+0xC]
    /* +0x10 */ struct {          // vector-like; *(rec+0x10) -> { [+0x0]=data, [+0x8]=count }
                  KpEntry *data;  //   *(*(rec+0x10) + 0x00)
                  ...;
                  uint32_t count; //   *(*(rec+0x10) + 0x08)
                } *vec;
} GeomRecord;
```

(Field names are best-effort. The load-bearing facts are the **offsets** and the
**index arithmetic**, which are exact.)

## Pseudocode

```c
void sub_180005930(StreamReader *stream, GeomRecord *rec)   // 0x180005930
{
    // ---- prologue / stack canary ----
    // save rbx,rbp,rsi,rdi,r12; sub rsp,0x50
    rsi = rec;                                              // 0x180005951  (rsi = arg2)
    r12 = stream;                                           // 0x18000595e  (r12 = arg1)
    uint64_t canary = __security_cookie ^ rsp;              // 0x180005942..0x18000594c -> [rsp+0x40]

    // ---- 1) read an 8-byte field into rec+0x20 ----
    //   sub_180006610(dst = rec+0x20, src = stream, n = 8)
    //   (arg order: rcx=stream(r12), rdx=rec+0x20, r8d=8)  NOTE call sets rcx=r12 below
    sub_180006610(/*rcx*/ r12, /*rdx*/ rec + 0x20, /*r8d*/ 8); // 0x18000595a..0x180005961  read 8 bytes -> rec[0x20..0x27]

    // ---- 2) read 1 byte -> [rsp+0x22], store as the vector count ----
    sub_1800065e0(/*rcx*/ r12, /*rdx*/ &stack[0x22]);       // 0x180005966..0x18000596e  read 1 byte -> [rsp+0x22]
    rax = *(void**)(rsi + 0x10);                            // 0x180005973  rax = rec->vec
    r8d = (uint8_t)stack[0x22];                             // 0x180005977
    *(uint32_t*)(rax + 0x8) = r8d;                          // 0x18000597d  rec->vec->count = byte

    // ================= LOOP 1: read each keypoint entry =================
    rax = *(void**)(rsi + 0x10);                            // 0x180005981
    edi = 0; ebp = 0;                                       // 0x180005985 (edi=0), 0x18000598a (ebp=index)
    if ((uint32_t)*(uint32_t*)(rax + 0x8) <= edi)           // 0x180005987 cmp count,0
        goto L_after_loop1;                                 // 0x18000598c jbe 0x1800059f3

  L_loop1:                                                  // 0x180005990
    rdx = *(void**)(rax + 0x0);                             // 0x180005990  rdx = vec->data
    ebx = ebp;                                              // 0x180005993  ebx = index
    r8d = 0x10;                                             // 0x180005995  n = 16
    rbx <<= 5;                                              // 0x18000599b  byteoff = index * 0x20
    rdx = *(void**)(rbx + rdx);                             // 0x1800059a2  src = ((KpEntry*)data)[index].blob  (*(data + idx*0x20))
    sub_180006610(/*rcx*/ r12, /*rdx*/ src, /*r8d*/ 0x10);  // 0x18000599f..0x1800059a6  read 16 bytes into that sub-blob

    sub_1800065e0(/*rcx*/ r12, /*rdx*/ &stack[0x20]);       // 0x1800059ab..0x1800059b3  read 1 byte -> [rsp+0x20]
    sub_1800065e0(/*rcx*/ r12, /*rdx*/ &stack[0x21]);       // 0x1800059b8..0x1800059c0  read 1 byte -> [rsp+0x21]

    rax = *(void**)(rsi + 0x10);                            // 0x1800059c5  rec->vec
    r11d = (uint8_t)stack[0x20];                            // 0x1800059c9
    rcx = *(void**)(rax + 0x0);                             // 0x1800059cf  data base
    ebp += 1;                                               // 0x1800059d2  index++
    *(uint32_t*)(rcx + rbx + 0x14) = r11d;                  // 0x1800059d5  entry[idx].f14 = byte@0x20
    rax = *(void**)(rsi + 0x10);                            // 0x1800059da
    edx = (uint8_t)stack[0x21];                             // 0x1800059de
    rcx = *(void**)(rax + 0x0);                             // 0x1800059e3
    *(uint32_t*)(rcx + rbx + 0x18) = edx;                   // 0x1800059e6  entry[idx].f18 = byte@0x21
    rax = *(void**)(rsi + 0x10);                            // 0x1800059ea
    if (ebp < (uint32_t)*(uint32_t*)(rax + 0x8))            // 0x1800059ee..0x1800059f1 cmp ebp,count ; jb
        goto L_loop1;

  L_after_loop1:                                            // 0x1800059f3
    // ---- 3) read 1 byte -> rec+0xC (header byte 'hdrC') ----
    rdx = rec + 0x10;  rdx += 0xC;  // i.e. &rec[0x1C]? NO — see note
    //   actually: rdx = *(rsi+0x10)?  NO. Disasm: mov rdx,[rsi+0x10]; add rdx,0xC  -> rdx = rec->vec + 0xC
    rdx = (uint8_t*)(*(void**)(rsi + 0x10)) + 0xC;          // 0x1800059f3,0x1800059fa
    sub_1800065e0(/*rcx*/ r12, /*rdx*/ rdx);                // 0x1800059f7..0x1800059fe  read 1 byte -> vec[+0xC]

    // ---- 4) read 1 byte -> rec+0xC (the GeomRecord header, NOT the vec) ----
    rdx = rec + 0xC;                                        // 0x180005a03  lea rdx,[rsi+0xC]
    sub_1800065e0(/*rcx*/ r12, /*rdx*/ rec + 0xC);          // 0x180005a07..0x180005a0a  read 1 byte -> rec[0xC]  ('hdrC')

    // ================= LABEL BLOCK A: 11 sub-tables, each prefixed by a 1-byte count =================
    //   for tile = 0..10 (ebp counts to 0xB):
    //       read 1 byte 'n' into stack[0x28 + tile]
    //       for j = 0..n-1:  data[j].f14 = tile * 0xF
    r11 = *(void**)(rsi + 0x10);                            // 0x180005a0f
    if ((uint32_t)*(uint32_t*)(r11 + 0x8) <= /*edi==*/0)    // 0x180005a13..0x180005a17  if count==0
        goto L_blockB_tail;                                 // 0x180005b4b  (skip A entirely)
    ebp = 0;                                                // 0x180005a1d  tile index
    rbx = &stack[0x28];                                     // 0x180005a1f  ptr into per-tile count array

  L_blockA_outer:                                           // 0x180005a24
    sub_1800065e0(/*rcx*/ r12, /*rdx*/ rbx);                // 0x180005a24..0x180005a2a  read 1 byte -> *rbx = n_this_tile
    eax = (uint8_t)*rbx;                                    // 0x180005a2f  n = count for this tile
    r11d = (uint8_t)bpl;                                    // 0x180005a32  tile
    r11d = r11d * 0xF;                                      // 0x180005a36  label = tile * 15
    edi = 0;                                                // (edi already 0; reused as j)
    rdx = (int64_t)(int32_t)edi;                            // 0x180005a3c  movsxd j  (signed)
    if (0 /*edi*/ >= eax) goto L_blockA_next;               // 0x180005a3a..0x180005a3f  if j>=n skip inner
    rdx <<= 5;                                              // 0x180005a41  rdx = j * 0x20

  L_blockA_inner:                                           // 0x180005a50
    rax = *(void**)(rsi + 0x10);                            // 0x180005a50  rec->vec
    edi += 1;                                               // 0x180005a54  j++
    rdx += 0x20;                                            // 0x180005a57  advance one entry (pre-add then write at -0x14)
    rcx = *(void**)(rax + 0x0);                             // 0x180005a5b  data base
    *(uint32_t*)(rcx + rdx - 0x14) = r11d;                  // 0x180005a5e  data[j].f14 = tile*15   (rdx-0x14 == j*0x20 + 0xC)
    eax = (uint8_t)*rbx;                                    // 0x180005a63  reload n
    if (edi < eax) goto L_blockA_inner;                     // 0x180005a66..0x180005a68

  L_blockA_next:                                            // 0x180005a6a
    edi = (uint8_t)*rbx;                                    // 0x180005a6a  (carry n as next edi seed)
    ebp += 1;                                               // 0x180005a6d  tile++
    rbx += 1;                                               // 0x180005a70  next per-tile count slot
    if (ebp < 0xB) goto L_blockA_outer;                     // 0x180005a74..0x180005a77  11 tiles total

    // ================= BLOCK B: write 0xA5 into data[k].f14 for k in [0 .. count12) =================
    //   count12 = rec->vec[+0xC]  (the byte read at step 3); label value = 0xA5
    ecx = (uint8_t)stack[0x32];                             // 0x180005a79  (this is stack[0x28+0xA] = 11th per-tile count)
    r8 = *(void**)(rsi + 0x10);                             // 0x180005a7e
    eax = (uint8_t)*(uint8_t*)(r8 + 0xC);                   // 0x180005a82  m = vec[+0xC]
    rdx = rcx;                                              // 0x180005a87  k = ecx (start index)
    if (ecx >= eax) goto L_blockC;                          // 0x180005a8a..0x180005a8c  if k>=m skip
    rdx <<= 5;                                              // 0x180005a8e  rdx = k*0x20

  L_blockB:                                                 // 0x180005a92
    rax = *(void**)(r8 + 0x0);                              // 0x180005a92  data base
    ecx += 1;                                               // 0x180005a95  k++
    rdx += 0x20;                                            // 0x180005a98
    *(uint32_t*)(rdx + rax - 0x14) = 0xA5;                  // 0x180005a9c  data[k].f14 = 0xA5
    r8 = *(void**)(rsi + 0x10);                             // 0x180005aa4
    eax = (uint8_t)*(uint8_t*)(r8 + 0xC);                   // 0x180005aa8  reload m
    if (ecx < eax) goto L_blockB;                           // 0x180005aad..0x180005aaf

  L_blockC:                                                 // 0x180005ab1
    // ================= LABEL BLOCK C: 11 more sub-tables (tiles 11..21), label = (tile-11)*0xF =================
    rax = *(void**)(rsi + 0x10);                            // 0x180005ab1
    ebp = 0xB;                                              // 0x180005ab5  tile starts at 11
    rdi = &stack[0x33];                                     // 0x180005aba  per-tile count ptr
    ebx = (uint8_t)*(uint8_t*)(rax + 0xC);                  // 0x180005abf  ebx = m (vec[+0xC]) — used as inner start index

  L_blockC_outer:                                           // 0x180005ac3
    sub_1800065e0(/*rcx*/ r12, /*rdx*/ rdi);                // 0x180005ac3..0x180005ac9  read 1 byte -> *rdi = n_this_tile
    eax = (uint8_t)*rdi;                                    // 0x180005ace  n
    r11d = ebp - 0xB;                                       // 0x180005ad1  lea r11d,[rbp-0xb]  (tile - 11)
    r8d = (uint8_t)r11b;                                    // 0x180005ad5
    rdx = (int64_t)(int32_t)ebx;                            // 0x180005ad9  movsxd start index (signed)
    r8d = r8d * 0xF;                                        // 0x180005adc  label = (tile-11)*15
    if (ebx >= eax) goto L_blockC_next;                     // 0x180005ae0..0x180005ae2
    rdx <<= 5;                                              // 0x180005ae4  rdx = idx*0x20

  L_blockC_inner:                                           // 0x180005af0
    rax = *(void**)(rsi + 0x10);                            // 0x180005af0
    ebx += 1;                                               // 0x180005af4  idx++
    rdx += 0x20;                                            // 0x180005af7
    rcx = *(void**)(rax + 0x0);                             // 0x180005afb
    *(uint32_t*)(rcx + rdx - 0x14) = r8d;                   // 0x180005afe  data[idx].f14 = (tile-11)*15
    eax = (uint8_t)*rdi;                                    // 0x180005b03  reload n
    if (ebx < eax) goto L_blockC_inner;                     // 0x180005b06..0x180005b08

  L_blockC_next:                                            // 0x180005b0a
    ebx = (uint8_t)*rdi;                                    // 0x180005b0a  carry n as next start index
    ebp += 1;                                               // 0x180005b0d  tile++
    rdi += 1;                                               // 0x180005b10
    if (ebp < 0x16) goto L_blockC_outer;                    // 0x180005b14..0x180005b17  until tile==22 (11 more tiles)

    // ================= BLOCK D: write 0xA5 for k in [stack[0x3d] .. count) =================
    ecx = (uint8_t)stack[0x3d];                             // 0x180005b19  start index (the 11th block-C per-tile count)
    rax = *(void**)(rsi + 0x10);                            // 0x180005b1e
    rdx = rcx;                                              // 0x180005b25
    if (ecx >= (uint32_t)*(uint32_t*)(rax + 0x8)) goto L_blockB_tail; // 0x180005b22,0x180005b28  k>=count
    rdx <<= 5;                                              // 0x180005b2a

  L_blockD:                                                 // 0x180005b30
    rax = *(void**)(rax + 0x0);                             // 0x180005b30  data base
    ecx += 1;                                               // 0x180005b33
    rdx += 0x20;                                            // 0x180005b36
    *(uint32_t*)(rdx + rax - 0x14) = 0xA5;                  // 0x180005b3a  data[k].f14 = 0xA5
    rax = *(void**)(rsi + 0x10);                            // 0x180005b42
    if (ecx < (uint32_t)*(uint32_t*)(rax + 0x8)) goto L_blockD; // 0x180005b46..0x180005b49

  L_blockB_tail:                                            // 0x180005b4b  (common exit label)
    // ---- epilogue / canary check ----
    __security_check_cookie(stack[0x40] ^ rsp);            // 0x180005b4b..0x180005b53  call 0x1800db580
    // restore rbx,rbp,r12,rdi,rsi; ret
    return;                                                 // 0x180005b6c
}
```

### Reader-helper semantics (callees)

- `sub_1800065e0(stream, dst)` — read **1 byte**: `memcpy(dst, stream->base + stream->cursor, 1); stream->cursor += 1;`
  (calls `sub_1800031e0` with n=1, then `*(stream+0x10) += 1`).
- `sub_180006610(stream, dst, n)` — read **n bytes**, one byte per iteration:
  `for(i=0;i<n;i++){ memcpy(dst+i, stream->base + stream->cursor, 1); stream->cursor++; }`
  (loops `sub_1800031e0` with n=1). Returns early if `n==0`.
- `sub_1800031e0(dst, src, n)` — `memcpy`: fast 4-byte-word copy if both ptrs 4-aligned and n%4 consistent, else byte copy.

So the whole record is consumed **one byte at a time** from `stream->cursor`; the
serialization is therefore a tight little-endian byte stream with no padding.

## Struct fields & constants

### Stream reader object (rcx / r12)
| Access | Meaning |
|---|---|
| `*(stream+0x08)` | base pointer of serialized buffer |
| `*(uint32_t*)(stream+0x10)` | read cursor (advanced 1 byte per read) |

### GeomRecord (rdx / rsi)
| Access | Meaning |
|---|---|
| `rec+0x20` (8 bytes) | first field read (some 8-byte header/id), `sub_180006610(...,8)` @0x18000595a |
| `rec+0x0C` (1 byte) | `hdrC` header byte read @0x180005a07 |
| `*(void**)(rec+0x10)` | pointer to the vector object (`vec`) |

### Vector object (`vec = *(rec+0x10)`)
| Access | Meaning |
|---|---|
| `*(void**)(vec+0x00)` | `data` — base of `KpEntry[]`, stride `0x20` |
| `*(uint32_t*)(vec+0x08)` | `count` — number of keypoint entries (set from a byte @0x18000597d) |
| `*(uint8_t*)(vec+0x0C)` | `m` — secondary count used as start/limit for Block B and Block C inner loops (read @0x1800059f7) |

### KpEntry (`data[i]`, stride 0x20)
| Access | Meaning |
|---|---|
| `*(void**)(data + i*0x20 + 0x00)` | sub-blob pointer; 16 bytes are read into it @0x18000599f (likely the 16-byte descriptor / coord packet) |
| `*(uint32_t*)(data + i*0x20 + 0x14)` | `f14` — set to byte@0x20 in loop1, then **overwritten** as a tile-label (`tile*15`, `(tile-11)*15`, or `0xA5`) by the four label blocks |
| `*(uint32_t*)(data + i*0x20 + 0x18)` | `f18` — set to byte@0x21 in loop1 |

> Note the label loops compute address as `(rdx pre-incremented by 0x20) - 0x14`, i.e.
> they advance the entry pointer **before** writing, so the first written entry index is
> the start index, and the written field is `data[idx]+0x14` (== `idx*0x20 + 0xC`
> relative to a 0-based `rdx<<5`, because `rdx` started at `idx*0x20` and `+0x20-0x14 = +0xC`...
> — see GDB hooks; treat the *written field* as `data[idx].f14` per the pointer math, verify dynamically).

### Stack locals
| Slot | Meaning |
|---|---|
| `[rsp+0x40]` | stack canary |
| `[rsp+0x20]` | scratch byte (loop1 field A -> f14) |
| `[rsp+0x21]` | scratch byte (loop1 field B -> f18) |
| `[rsp+0x22]` | scratch byte (vector count) |
| `[rsp+0x28 .. 0x32]` | Block A per-tile counts (11 bytes, tiles 0..10); `[rsp+0x32]` reused as Block B start index |
| `[rsp+0x33 .. 0x3d]` | Block C per-tile counts (11 bytes, tiles 11..21); `[rsp+0x3d]` reused as Block D start index |

### Magic constants
| Const | Meaning |
|---|---|
| `0x8` | size of first header field read into `rec+0x20` |
| `0x10` (16) | bytes read into each `KpEntry.blob` |
| `0x20` (32) | `KpEntry` stride (`shl 5`) |
| `0xF` (15) | per-tile label multiplier: `label = tile_index * 15` |
| `0xB` (11) | tile count per label block (Block A: tiles 0..10; Block C: tiles 11..21) |
| `0x16` (22) | Block C loop bound (`ebp` goes 11→22) |
| `0xA5` (165) | sentinel/"unassigned" label written to leftover entries (Blocks B and D) |
| `0x14` (offset) | write offset within entry for the label field (`rdx-0x14`) |

## Callees
- `0x1800065e0` — read 1 byte from stream into dst, advance cursor (see above). `func_1800065e0.S`.
- `0x180006610` — read N bytes from stream into dst, advance cursor by N (see above). `func_180006610.S`.
- `0x1800031e0` (transitive, via both readers) — `memcpy(dst,src,n)`. `func_1800031e0.S`.
- `0x1800db580` — `__security_check_cookie` (stack-canary epilogue check), standard MSVC idiom.

## GDB verification hooks

The goal is to confirm a Python re-implementation reads the same bytes in the same
order and produces the same per-entry labels. Set:

1. `break *0x18000595a` — entry of the first read.
   - Dump `rcx` (stream obj), `*(uint64_t*)(rcx+0x8)` (base) and `*(uint32_t*)(rcx+0x10)` (cursor at start), `rdx` (= `rec+0x20`). Confirms where the 8-byte header lands and the starting cursor.

2. `break *0x18000597d` — vector count write.
   - Dump `r8d` (the count byte), `rax` (= `vec`), then `*(uint32_t*)(rax+0x8)` after step. This is `vec->count`.

3. `break *0x18000599f` — per-entry 16-byte blob read (inside LOOP 1).
   - Dump `ebp` (entry index), `rbx` (= `index<<5`), `rdx` (src blob ptr = `*(data+index*0x20)`), `*(uint32_t*)(stream+0x10)` (cursor). Then after `0x1800059a6` dump 16 bytes at the dst to capture the descriptor/coord packet.

4. `break *0x1800059d5` — write `entry.f14` from byte@0x20 (loop1).
   - Dump `r11d` (byte value), `rcx` (data base), `rbx` (index<<5); written addr = `rcx+rbx+0x14`.

5. `break *0x1800059e6` — write `entry.f18` from byte@0x21 (loop1).
   - Dump `edx`, addr `rcx+rbx+0x18`.

6. `break *0x180005a07` — read `hdrC` into `rec+0xC`. Dump `rdx` (= `rec+0xC`) and cursor.

7. `break *0x180005a24` — Block A outer (per-tile count read).
   - Dump `ebp` (tile 0..10), `rbx` (= `&stack[0x28+tile]`), cursor. After the read, `*(uint8_t*)rbx` = this tile's count `n`.

8. `break *0x180005a5e` — Block A label write. **This is the key transform-label line.**
   - Dump `r11d` (= `tile*15`, the label), `rcx` (data base), `rdx` (entry offset), written addr `rcx+rdx-0x14`, and `edi` (j). Verify `label == tile_index*15`.

9. `break *0x180005a9c` — Block B sentinel write.
   - Dump `ecx` (k), `rax` (data base), `rdx`, addr `rdx+rax-0x14`; written value is constant `0xA5`. Also dump `*(uint8_t*)(rsi... vec)+0xC)` = `m`.

10. `break *0x180005afe` — Block C label write (tiles 11..21).
    - Dump `r8d` (= `(tile-11)*15`), `ebp` (raw tile 11..21), `ebx` (idx), `rcx` (data base), `rdx`. Verify `label == (tile-11)*15`.

11. `break *0x180005b3a` — Block D sentinel write.
    - Dump `ecx` (k), addr `rdx+rax-0x14`, value `0xA5`; compare against `vec->count` (`*(uint32_t*)(vec+0x8)`).

12. `break *0x180005b4b` (exit) — dump the whole `data[]` array: for `i` in `0..count-1` print `*(uint32_t*)(data + i*0x20 + 0x14)` and `+0x18`. This is the full set of per-entry labels the Python port must match byte-for-byte.

To find `data` and `count` generically at any hook: `set $vec = *(void**)($rsi+0x10)`,
`set $data = *(void**)$vec`, `set $cnt = *(unsigned int*)($vec+0x8)`.

## Confidence & open questions

**Solid (directly from disasm):**
- This is a byte-stream deserializer; both callees are confirmed cursor-advancing readers (`sub_1800065e0`=1 byte, `sub_180006610`=N bytes) over `mempcy` `sub_1800031e0`.
- The read order: 8-byte header → 1-byte count → per-entry {16-byte blob, 1 byte, 1 byte} → 1 byte `hdrC` → label blocks.
- The four label blocks write into `KpEntry+0x14`: Block A labels `tile*15` for 11 tiles, Block B fills `0xA5`, Block C labels `(tile-11)*15` for 11 more tiles, Block D fills `0xA5`. Constants `0xF`, `0xB`, `0x16`, `0xA5`, `0x20` are exact.
- **No fixed-point, trig, sqrt, matrix, RANSAC, or coordinate arithmetic** appears here. The only arithmetic is `index*15` label computation and `index<<5` strides.

**Inferred / to verify dynamically:**
- The precise meaning of the entry fields (`+0x14`, `+0x18`) and the 16-byte blob — named "label/tile membership" because of the `*15` and `0xA5` writes, but the loop1 byte values written there are first then overwritten, so the *final* `f14` is always a tile label or `0xA5`. The 16-byte blob is most likely the keypoint coordinate+descriptor packet (verify with hook 3).
- Block B's start index comes from `stack[0x32]` and Block D's from `stack[0x3d]`. Those are the 11th per-tile count of each block (the last byte read in the A/C loops written one past the 11-slot range). The exact intended semantics (cumulative offset vs. independent index) should be confirmed with hooks 7/9/10/11 against a real capture — i.e. whether the inner-loop "start index" `ebx`/`ecx` is meant to be a *running cursor across tiles* (it is reused, suggesting cumulative coverage of the entry array) is the main open question.
- Whether `rec+0x20` is an id/timestamp vs. a transform parameter block: it is read as opaque 8 bytes; this function does not interpret it.

**Relevance to sec0_pre transforms:** this loader produces the *labeled keypoint table*
that downstream transform-fitting (the actual Q16 rigid/similarity solve) consumes — it
is upstream plumbing, not the transform math itself.
