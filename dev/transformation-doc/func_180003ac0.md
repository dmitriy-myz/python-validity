# sub_180003ac0 — Rasterize a list of (dilated) box records into a w×h label/mask buffer

This is **not** transform math. It is an orchestrator that (1) fills an output
`w*h` byte buffer with `0xFF`, then (2) iterates over a list of fixed-stride
(0x20 = 32-byte) records and stamps each record's clamped, ±2-dilated rectangle
into the buffer with the record's **index** as the fill value (via `sub_180003a00`).
The result is a per-pixel label / ownership map (each pixel = which box covers
it, default `0xFF` = "none"). It feeds the tiling/region bookkeeping in the
template pipeline, not the rigid Q16 transform fit.

## Signature

```c
// arg0 rcx : uint8_t *out_mask      // output buffer, w*h bytes (the label map)
// arg1 rdx : BoxList   *list        // { void *data;  ...;  uint32_t count @ +0x8 }
// arg2 r8b : uint8_t    w           // row stride / clamp-limit on the +0x14 axis
// arg3 r9b : uint8_t    h           // clamp-limit on the +0x18 axis
void sub_180003ac0(uint8_t *out_mask, BoxList *list, uint8_t w, uint8_t h);
```

Notes / guesses:
- `w` and `h` are passed as **bytes** (`movzx`), so each is 0..255; the buffer
  size is `w*h` (`imul r8d,esi`). They are most likely a tile/region grid size
  (e.g. 0..255 cells), not full-resolution image dimensions.
- `list` layout: `*(void**)(rdx+0) = record table base`, `*(uint32_t*)(rdx+0x8) = count`.
  Only these two fields are touched here.
- Each record is **0x20 bytes**; the rasterizer reads `int32 @ +0x14` and `int32 @ +0x18`
  (see `sub_180003a00`).

## Pseudocode

```c
void sub_180003ac0(uint8_t *out_mask /*rcx->r12*/,
                   BoxList  *list    /*rdx->rdi*/,
                   uint8_t   w       /*r8b->ebp*/,
                   uint8_t   h       /*r9b->esi*/)
{
    // ---- prologue 0x180003ac0..0x180003ad6 ----
    // save rbx,rbp,rsi,rdi to shadow space; push r12; sub rsp,0x40
    uint32_t W = (uint8_t)w;                       // movzx ebp,r8b   0x180003ada
    uint32_t H = (uint8_t)h;                        // movzx esi,r9b   0x180003ade
    rdi = list;                                     // mov rdi,rdx     0x180003ae2
    // memset(out_mask, 0xFF, W*H):
    //   rcx = out_mask (=r12), dl = 0xFF, r8d = W*H
    r8d  = W * H;                                   // imul r8d,esi    0x180003aed (W in r8d via ebp, *H)
    dl   = 0xFF;                                     // mov dl,0xFF     0x180003ae8
    r12  = out_mask;                                // mov r12,rcx     0x180003aea
    sub_1800031c0(/*rcx=*/out_mask, /*dl=*/0xFF, /*r8d=*/W*H);  // call 0x180003af1  -> memset(out_mask,0xFF,W*H)

    // ---- loop over records: i in [0, list->count) ----
    uint32_t i = 0;                                 // xor ebx,ebx     0x180003af6
    if (list->count == 0) goto done;                // cmp [rdi+8],ebx / jbe  0x180003af8/0x180003afb
    do {                                            // L_180003b00:
        void *table = *(void**)(rdi + 0);           // mov rax,[rdi]   0x180003b00  (record table base)
        // outgoing stack args for sub_180003a00 (ac0-frame offsets):
        //   [rsp+0x30] = table       (-> callee [rsp+0x38] = record base)   0x180003b0a
        //   [rsp+0x28] = out_mask    (-> callee [rsp+0x30] = dst buffer)     0x180003b16
        //   [rsp+0x20] = (uint8_t)H  (-> callee [rsp+0x28] = clamp-limit h)  0x180003b1b
        // register args:
        //   rcx = i                  (record index -> *0x20 stride)          0x180003b14
        //   edx = 2                  (dilation / margin in cells)            0x180003b0f
        //   r8d = i                  (fill value byte = record index)        0x180003b07
        //   r9b = (uint8_t)W         (row stride / clamp-limit w)            0x180003b03
        sub_180003a00(/*rcx*/ i, /*edx*/ 2, /*r8d*/ i, /*r9b*/ (uint8_t)W,
                      /*[+0x28]*/ (uint8_t)H, /*[+0x30]*/ out_mask, /*[+0x38]*/ table);
                                                    // call 0x180003b20
        i += 1;                                     // add ebx,1       0x180003b25
    } while (i < list->count);                      // cmp/jb          0x180003b28/0x180003b2b
done:
    // ---- epilogue 0x180003b2d..0x180003b47 ----
    // restore rbx,rbp,rsi,rdi from shadow; add rsp,0x40; pop r12; ret
}
```

### What `sub_180003a00` does (the per-record rasterizer — summarized; full doc TBD)
Treats the index-i record (`base + i*0x20`) as a box:
```
lo = *(int32*)(base + i*0x20 + 0x14);   // 0x180003a28  (axis-A center, along stride W)
hi = *(int32*)(base + i*0x20 + 0x18);   // 0x180003a2d  (axis-B center, along clamp H)
m  = 2;                                 // edx margin (dilation)
a0 = max(lo - m, 0);  a1 = min(lo + m, W);   // clamp to [0, W]
b0 = max(hi - m, 0);  b1 = min(hi + m, H);   // clamp to [0, H]
for (row = b0; row < b1; ++row)
    for (col = a0; col < a1; ++col)
        out_mask[row*W + col] = (uint8_t)i;  // 0x180003a99  (fill value = record index, low byte)
```
i.e. it stamps a `(2*m+1)`-ish clamped square of value `i` (the record index)
into the `W`-stride buffer. Default background stays `0xFF`.

## Struct fields & constants

| Access (in ac0)                | Meaning                                              |
|--------------------------------|------------------------------------------------------|
| `*(void**)(rdx + 0x0)`         | `list->data` — base of the 0x20-byte record table    |
| `*(uint32_t*)(rdx + 0x8)`      | `list->count` — number of box records (loop bound)   |
| `(uint8_t)r8b`                 | `w` — buffer row stride & clamp limit on +0x14 axis  |
| `(uint8_t)r9b`                 | `h` — clamp limit on +0x18 axis                      |

Per-record fields (read inside `sub_180003a00`, record stride **0x20**):

| Access (record+off)            | Meaning                                              |
|--------------------------------|------------------------------------------------------|
| `*(int32_t*)(rec + 0x14)`      | center coord on the W-stride axis                    |
| `*(int32_t*)(rec + 0x18)`      | center coord on the H axis                           |

Magic constants:
- `0xFF` — background / "no box" fill value for the whole buffer (memset).
- `2`    — dilation margin (cells) added on every side of each box.
- `0x20` (32) — record stride (`shl r10,0x5` in callee).
- fill value per pixel = the **record index** (`i`, low byte), so indices must
  be < 0xFF to remain distinguishable from background.

No fixed-point, no >>16, no trig, no matrix ops here.

## Callees

- `0x1800031c0` — `memset`-with-positive-size guard: `if ((int)r8d > 0) call 0x1800e0a60(rcx, dl, r8d)`. Here used as `memset(out_mask, 0xFF, W*H)`. (`0x1800e0a60` is the CRT `memset`.)
- `0x180003a00` — per-record box rasterizer: stamps a clamped ±2-dilated square of value `i` (record index) into `out_mask`. See `func_180003a00.md` (not yet written).

## GDB verification hooks

Use these to confirm a Python re-implementation produces an identical label map.

- `break *0x180003af1` — just before the memset.
  - `rcx` = `out_mask` (dst base), `dl` low byte = `0xFF`, `r8d` = `W*H` (buffer size).
  - Also dump args: `rbp & 0xff` = `W`, `rsi & 0xff` = `H`, `rdi` = `list` ptr.
  - `x/2gx $rdi` → `list->data` (`[rdi]`) and at `[rdi+8]` the count: `x/wd $rdi+8`.

- `break *0x180003b00` — top of loop body (per record `i`).
  - `ebx` = current index `i`; `*(uint32_t*)($rdi+8)` = count (loop bound).
  - `rax`(after this insn) = `list->data` table base.

- `break *0x180003b20` — the call into the rasterizer, with all args staged.
  - `rcx` = `i`, `edx` = `2` (margin), `r8d` = `i` (fill value).
  - `r9b` = `W`. Stack: `x/gx $rsp+0x30` = table base, `x/gx $rsp+0x28` = out_mask,
    `x/bx $rsp+0x20` = `H`.

- Inside `sub_180003a00` (verify the actual box coords/extent — the load-bearing values):
  - `break *0x180003a28` then `break *0x180003a2d` — dump `r11d` (= `*(int32)(rec+0x14)`) and `ecx` (= `*(int32)(rec+0x18)`): the box center coords for record `i`.
  - `break *0x180003a64` — after clamping: `edi`=a0, `r11d`=a1, `r10d`=b0, `r9d`=b1 (the clamped inclusive/exclusive box bounds). These determine exactly which cells get stamped.
  - `break *0x180003a99` — the actual store `out_mask[r8d... ] = bl`; `bl` = fill value (= `i`), `r9`+`rax` = target address. Single-step the inner `do/while` to capture every written offset.

- After return to `0x180003b2d`, dump the whole buffer once: `dump binary memory /tmp/mask.bin $r12 $r12+(W*H)` (using the W,H captured at entry) and diff against the Python port byte-for-byte.

## Confidence & open questions

- **High confidence**: control flow (memset then per-record loop), the memset
  semantics (`0xFF`, `W*H`), record stride `0x20`, margin `2`, and that the
  fill value is the record index. These are direct reads of the disassembly.
- **High confidence** that `0x1800031c0`→`0x1800e0a60` is `memset` (size guarded
  `> 0`, byte fill in `dl`, dst in `rcx`) — matches the MSVC pattern and the
  many other `0x1800e0a60` call sites in `E0CA0.S`.
- **Medium confidence** on the `w`/`h` naming and which record field maps to
  which axis. The clamp limits are unambiguous (`+0x14`-axis clamps to `w`,
  `+0x18`-axis clamps to `h`), and the buffer is `W`-stride (`row*W+col`), but
  whether these are tile-grid extents vs. something else depends on the caller
  `sub_1800043d0` (which passes `imul`-derived `w*h` byte sizes from
  `[rsp+0x548]`/`[rsp+0x550]` — looks like two small grid dims).
- **Open**: exact meaning of record fields beyond +0x14/+0x18 (the record is
  0x20 bytes; only two int32s are used by this rasterizer). Full semantics of
  `sub_180003a00`'s lower offsets and whether `r8d=i` truly equals the fill
  byte in all callers should be confirmed when documenting `func_180003a00.md`.
- **Not transform math.** No fixed-point, matrix, atan2/sqrt, or
  RANSAC/voting here — this is geometry *bookkeeping* (a per-cell ownership/label
  raster), upstream of the sec0_pre Q16 transform fit.
